# 404 游戏

一个无需服务器即可运行的静态网页动作游戏。玩家在俯视角地图中移动、瞄准、拾取武器、清理敌人，把代表错误页的 `404` 逐步“修复”为 `200 OK`。

初始版来源：[https://iskra.graphics/404](https://iskra.graphics/404)。本项目是在该 404 游戏基础上的本地改造版本。

## 运行方式

直接用浏览器打开根目录的 `index.html` 即可游玩，不需要启动服务器。

项目入口：

- `index.html`：静态页面入口。
- `overprint/game.bundle.js`：已打包的游戏脚本。
- `overprint/src/`：游戏源码。

如需重新打包源码，可在项目根目录执行：

```bash
npx esbuild@0.25.9 overprint/src/main.js --bundle --format=iife --target=es2020 --outfile=overprint/game.bundle.js --log-level=warning
```

## 核心玩法

- 玩家每局从一个起始武器进入地图，击杀敌人、拾取地上武器，并尽量保持连杀节奏。
- 敌人会被声音、视线、尸体等线索吸引；防守模式中上一波尸体不会继续让下一波敌人警戒。
- 敌人视线以真实感知范围显示，巡逻者的感知距离更远。
- 玩家拥有主手和副手两个武器槽。副手只储存第二把武器，不直接攻击，但可以在战斗中按 `E` 切出。
- 部分武器从副手切回主手时会触发“换手技”：例如武士刀释放剑气，盾牌触发短距离冲锋并获得 3 秒无敌。
- 携带的主手 / 副手武器会在防守模式和下一局流程中尽量保留。
- 图鉴会在获得武器或遇到敌人后记录对应条目。

## 模式介绍

### 无限模式

标准流程模式。每局根据日期或自定义种子生成地图，清空当前层敌人后前往出口进入下一层。击杀、连击和清层速度会影响得分。

### 练习模式

可在标题页循环选择地形、武器和敌人类型，用于测试武器机制。练习模式包含稻草人训练目标，且不计入排行榜。

可选地形包括：

- 训练室
- 掩体房
- 长廊

### 防守模式

在地牢式地图里抵御一波波敌人。防守模式地图保证各区域可达，没有房间门，房间之间通过通路连接。

规则要点：

- 每波开始时，玩家所在房间不会刷新敌人。
- 每波清空后进入 2 分钟休息期。
- 休息期可按 `T` 或点击打开商店。
- 商店可购买武器、刷新商品、补充子弹、恢复生命，以及升级最大生命、攻击速度、冲刺槽、冲刺恢复和子弹时间。
- 准备完成后可按 `Enter` 或点击按钮提前结束休息。

## 武器机制

### 近战武器

| 武器 | 机制 |
| --- | --- |
| 赤手 | 基础近战，不致命，适合最后手段。 |
| 小刀 | 高速近战，命中可直接处决敌人，投掷也具有致命性。 |
| 球棒 | 攻击距离更长，适合击倒敌人和冲撞门类障碍。 |
| 屠夫之触 | 近战电锯型武器，会定期甩出长寿命电锯片。 |
| 电锯片 | 无差别范围威胁，持续时间较长，不会变回可拾取武器。 |

### 蓄力冲刺武器

| 武器 | 机制 |
| --- | --- |
| 武士刀 | 按住攻击蓄力；释放后冲刺并斩杀路径上的敌人，无视防御和盾牌。每斩杀一个敌人会刷新冲刺时间并进入子弹时间。满蓄力时会显示预览点，可瞬移到预览点附近的有效落点。 |
| 堂吉柯德 | 骑枪造型武器，蓄力后释放冲锋。效果类似武士刀的路径斩杀，但没有瞬移；冲锋期间继续按住蓄力可延长冲锋时间，但消耗速度仍快于补充速度。 |

### 常规枪械

| 武器 | 弹药 | 机制 |
| --- | ---: | --- |
| 手枪 | 7 | 稳定、节奏可靠，适合基础交战。 |
| 左轮 | 6 | 重弹、低射速，可穿门并削甲，对盾牌和装甲更有效。 |
| 冲锋枪 | 28 | 高射速压制，散布明显。 |
| 撕裂者 | 30 | 类似冲锋枪，但子弹可穿墙。 |
| 霰弹枪 | 2 | 近距离多弹丸爆发，后坐力和声音都较大。 |
| 暗杀 · D | 9 | 暗杀用枪，降低被识破压力。 |
| 狙击枪 | 5 | 子弹速度极快，穿透力极强，红外激光会指示弹道。 |
| 弹弹激光枪 | 18 | 能量弹可反弹，适合拐角和复杂空间。 |

### 爆炸物与投掷物

投掷物可按住攻击蓄力。蓄力不再放大爆炸半径，而是增加可选择的投掷范围；玩家仍可在范围内用鼠标选择落点。普通“投掷当前武器”不属于这套落点选择逻辑。

| 武器 | 弹药 | 机制 |
| --- | ---: | --- |
| 手雷 | 3 | 范围爆炸，声音大，可被盾牌正面防住。 |
| 破片手雷 | 3 | 爆炸半径较小，但会释放高速破片。 |
| 闪光弹 | 3 | 长时间瘫痪敌人，有概率让敌人乱开枪，也有概率使敌人掉落武器。 |
| 火箭弹 | 3 | 直线飞行的重型爆炸弹，可补弹，伤害和破盾能力强。 |
| 燃烧瓶 | 3 | 落点生成持续伤害地形；燃烧区属于无差别范围伤害。 |
| 哨戒机枪部署包 | 3 | 落点部署一挺自动机枪，弹容量、射速和散射度与冲锋枪一致。 |
| 毒蜂无人机部署包 | 3 | 落点释放 3 架小型无人机，每架 3 发子弹；子弹耗尽后会尝试靠近敌人自爆。 |

### 状态武器

| 武器 | 弹药 | 机制 |
| --- | ---: | --- |
| 疯狂毒镖 | 8 | 无声命中，使敌人永久发疯并无差别攻击；发疯敌人会优先选择附近其他敌人。 |
| 驯服毒标 | 6 | 无声命中，永久把敌人变为友军。 |
| 传染病毒 | 1 | 可无声投掷感染云；作为副手时，会让被驯服的友军具有传染性，被其杀死的敌人会转化为新的友军。 |
| 复制蘸料 | 1 | 主手使用时读取副手的状态效果，并转化为对应提取液。 |
| 疯狂提取液 | 1 | 可作为副手涂层，让主手攻击附带疯狂；主手使用会让玩家短暂失控。 |
| 驯化提取液 | 1 | 可作为副手涂层，让主手攻击附带驯化；主手对自己使用无效。 |
| 病毒提取液 | 1 | 可作为副手涂层，让主手攻击附带感染；主手使用会感染玩家。 |

### 防御武器

| 武器 | 机制 |
| --- | --- |
| 盾牌 | 正面格挡大多数攻击，包括远程、近战、冲刺和手雷等爆炸冲击；燃烧瓶、电锯片等无差别范围伤害无法被盾牌完全防御。玩家持盾格挡不消耗耐久。敌人也能持盾，但敌人盾牌有 5 点耐久，且无法防御玩家冲刺。盾牌从副手切出时会立刻向前冲锋一段距离，并获得 3 秒无敌。 |

## 换手技与副手联动

- `E` 会交换主手和副手。
- 副手中的普通武器切到主手后可立刻使用。
- 武士刀从副手切出时会向前释放一道剑气。
- 部分枪械从副手切出时会触发换手连射。
- 盾牌从副手切出时会触发盾牌冲锋和 3 秒无敌。
- 状态类副手可改变主手攻击效果，例如提取液作为副手时会给主手攻击附加疯狂、驯化或感染。
- 传染病毒作为副手时，会强化驯服毒标：被驯服友军杀死其他敌人后，可把尸体转化为新的友军。

## 敌人类型

| 敌人 | 行为 |
| --- | --- |
| 稻草人 | 静止靶，不巡逻、不警戒。 |
| 暴徒 | 普通近战敌人，会追逐并挥击。 |
| 枪手 | 持枪敌人，会保持距离并开火。 |
| 猎犬 | 高速冲刺敌人，贴身威胁强。 |
| 巡逻者 | 感知范围更远，会尽量遍历所有房间。 |
| 重盾 | 正面装甲分片破损，适合从侧面或用强破盾武器处理。 |

## 提示

- 敌人能听见枪声、爆炸、破门等噪声；无声武器适合先手控制。
- 盾牌很强，但燃烧、锯片等区域伤害依然危险。
- 防守模式中不要把休息期全等完：买好武器和升级后可以提前开波。
- 图鉴是学习武器和敌人形状的最佳位置；遇到或拾取后会自动补全。
