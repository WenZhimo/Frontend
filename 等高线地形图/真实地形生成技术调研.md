# 真实地形生成技术与 Minecraft 地形模组调研

生成日期：2026-07-11  
适用项目：当前 Three.js 等高线地形可视化 Demo

## 摘要

当前项目的地形“不自然”，主要不是因为使用了 Simplex noise，而是因为只使用了少量均匀噪声层，缺少真实地形常见的层级结构：大陆/海盆、山脉走向、河谷网络、侵蚀沉积、坡面稳定性、气候与地表覆盖。自然地形更像一套“生成管线”，而不是一个高度函数。

综合 Minecraft 官方世界生成、TerraForged、Tectonic、Terralith、RTG、Terra、World Machine、Gaea 与图形学地形论文，最适合本项目的升级路线是：

1. 用低频噪声生成大陆性、山脉带、谷地、湿润度等控制图。
2. 用 domain warping 打破噪声的网格感和团块感。
3. 用 ridged multifractal 生成山脊，而不是圆鼓鼓的随机山包。
4. 在高度图生成后加入轻量水蚀与热蚀。
5. 为等高线颜色和材质保留 slope、flow、deposition 等派生图层。

## 1. 当前项目问题诊断

`TerrainDataGenerator.js` 目前核心逻辑是两层 Simplex noise 叠加：一层大尺度起伏，一层更高频的细节。这种方法能快速生成连续高度场，但容易出现三个问题：

- **缺少地貌层级**：没有大陆、盆地、山脉、谷地之间的尺度差异。
- **缺少方向性**：真实山脉通常有长轴、褶皱或断裂方向；纯噪声常呈现均匀斑块。
- **缺少水文逻辑**：山谷没有被水流组织，河道、冲沟、沉积扇不会自然出现。

因此，改进重点不应只是“多叠几层噪声”，而是从“随机高度函数”改为“地貌管线”。

## 2. Minecraft 官方世界生成的参考价值

Minecraft 的世界生成可理解为多阶段流水线。官方 Bedrock 创作者文档说明，世界从 seed 与梯度噪声开始，先生成基础地形，再进入 biome、structure、feature 等阶段；biome 分布会考虑高度、温度、湿度、erosion 与 weirdness 等参数。[1]

Java 版自定义世界生成进一步暴露了 `noise_settings`、`density_function`、`noise_router`、`surface_rule` 等数据驱动概念。Minecraft Wiki 对 1.20.1 的自定义世界生成说明显示，Overworld 的最终密度由多个 density function 组合而来，`sloped_cheese`、`depth`、`factor`、`jaggedness` 等函数共同控制地表高度、山地锯齿、洞穴与过渡。[2]

这对本项目的启发是：不要用一个 `getHeight(u, v)` 直接回答所有地形问题。更自然的写法是先计算一组中间控制量：

```js
const continent = continentNoise(x, z);
const mountainMask = ridgeBeltNoise(x, z);
const erosionMask = erosionNoise(x, z);
const moisture = moistureNoise(x, z);
const baseHeight = continentToElevation(continent);
```

然后再组合为高度、颜色、等高线密度和材质。

## 3. Minecraft 地形模组案例

### 3.1 TerraForged

TerraForged 是 Minecraft Java 版世界生成模组，官方 CurseForge 页面描述它会重写原版生成系统，提供全新地形、更好的河流、自定义 biome features 和大量配置选项。[3] 其核心参考价值不只是“更漂亮”，而是它把世界生成视为可配置的大尺度地貌系统：地形、河流、树木、生物群系与兼容性一起考虑。

TerraForged 早期开发者介绍中还提到使用 hydraulic erosion 改善高度图风格：追踪大量水滴沿坡面移动，模拟侵蚀、搬运与沉积。这类说法来自社区发布帖，证据等级低于官方文档，但与 TerraForged 的视觉特征和地形生成论文中的常见做法一致。[4]

可借鉴点：

- 先生成可读的大地形，再用侵蚀增加真实细节。
- 河流不只是贴图，而是影响谷地与地形组织。
- 参数应能控制 continent size、river spread、mountain scale 等宏观特征。

### 3.2 Tectonic

Tectonic 的 Modrinth 页面称它是一个“改变地形塑造方式”的世界生成项目，并列出 continent-like landmasses、数千到数万方块宽的大陆、更深海洋、更丰富海底地形等特征。[5] 它尤其适合作为“大尺度结构”的参考：不是每个局部都追求复杂，而是让远景尺度有大陆、岛屿、深海、山脉和高原的秩序。

可借鉴点：

- 低频地貌控制比高频细节更重要。
- 山脉需要长尺度连续性，而不是独立随机峰。
- 海洋/低地/高原的高度分布应有不同曲线。

### 3.3 Terralith

Terralith 是 Stardust Labs 的世界生成数据包/模组。Modrinth 页面称其基于 Minecraft 1.18 的世界生成大改，新增 95+ biomes，并加入峡谷、破碎地貌、浮岛、深海沟等新 terrain types。[6] Terralith 的重点不是严格物理真实，而是“现实地貌 + 轻幻想 + 探索节奏”的组合。

可借鉴点：

- 地形真实感不只来自高度，还来自“地貌主题”的切换。
- biome 可以是地形算法的选择器：火山、峡谷、高地、绿洲应使用不同生成公式。
- 对可视化项目而言，可把 biome 简化为颜色带、地貌类型和等高线样式。

### 3.4 Realistic Terrain Generation（RTG）

RTG 的官方 CurseForge 页面说明，它不添加新方块、生物或 biome，而是为现有 Overworld biomes 生成更真实的地形。[7] 这对本项目很有启发：即便不新增复杂资源，也可以只通过高度场算法改善观感。

可借鉴点：

- “地形生成”和“内容添加”可以分离。
- 在当前项目里，优先改 `TerrainDataGenerator.js`，不用马上引入新渲染系统。

### 3.5 Biomes O' Plenty

Biomes O' Plenty 是经典 biome 扩展模组，官方页面描述其向 Overworld、Nether、End 添加大量新 biome、植物、树木和方块，并在新版本依赖 TerraBlender 接入世界生成。[8] 它不是最适合参考高度图算法的对象，但很适合参考“生态差异如何增强真实感”。

可借鉴点：

- 同一套地形高度，如果地表颜色、植被、岩层完全一样，仍会显得假。
- 未来可以用 moisture/temperature/slope 生成地表色带：雪线、裸岩、草地、沙地、河谷沉积。

### 3.6 Terra 平台

Terra 是 Minecraft 世界生成配置平台，其文档强调世界生成中的随机方面大多受 noise 影响，并提供 noise sampler、fractalization、domain warping、sampler composition 等配置概念。[9] 它的价值在于把地形生成抽象成可组合节点，而不是硬编码单个函数。

可借鉴点：

- 把噪声、遮罩、混合函数拆成独立 sampler。
- 用组合而不是堆叠，让算法更容易调参和替换。

## 4. 真实地形生成技术谱系

### 4.1 分形噪声与 fBm

fBm（fractional Brownian motion）通过多 octave 噪声叠加产生多尺度细节，是游戏地形的基础技术。FastNoiseLite 文档把 fBm、ridged、ping-pong 等列为 fractal 类型，并提供 Perlin、Simplex、Cellular 等基础噪声类型。[10]

优点：

- 简单、快速、可 seed、适合实时。
- 很适合作为丘陵、粗糙度、局部扰动。

局限：

- 单独使用会显得“随机纹理贴在地上”。
- 缺少河流组织、山脉成因、沉积和坡面逻辑。

### 4.2 Domain Warping

Domain warping 的做法是先用噪声扭曲采样坐标，再采样主要高度函数：

```js
const wx = x + warpNoiseX(x, z) * warpStrength;
const wz = z + warpNoiseZ(x, z) * warpStrength;
const h = baseNoise(wx, wz);
```

FastNoiseLite/Godot 文档描述 domain warp 会使用另一个 FastNoiseLite 实例扭曲空间，从而产生 noise distortion；它还暴露 warp amplitude、frequency、octaves、gain、lacunarity 等参数。[10]

对当前项目，domain warping 是最划算的第一步：不用改渲染器，只需改变高度采样方式，就能让山脊和谷地从“圆形噪声团块”变成弯曲、连续、类似自然褶皱的结构。

### 4.3 Ridged Multifractal

Ridged noise 通常用 `1 - abs(noise)` 或类似变换生成山脊。FastNoiseLite 文档也把 `FRACTAL_RIDGED` 描述为能产生 ridged look 的 fractal 组合方式。[10]

适用场景：

- 连绵山脉。
- 锐利山脊。
- 峡谷边缘。

当前项目可以把 ridged noise 只应用在 `mountainMask` 高的区域，避免全图都长成尖锐山脉。

### 4.4 Hydraulic Erosion（水蚀）

水蚀是提升真实感最关键的技术之一。图形学中常见两大类：

- **粒子/水滴法**：模拟大量水滴沿坡面移动，侵蚀、携带、沉积泥沙。
- **网格/浅水模型**：在高度网格上模拟水量、速度、流量和泥沙交换。

Mei、Decaudin、Hu 的 “Fast Hydraulic Erosion Simulation and Visualization on GPU” 是经典 GPU 水蚀工作，目标是在 GPU 上快速模拟与可视化水蚀。[11] Krištof 等人的 SPH 方法则把水流粒子与地形边界粒子结合，用于地形侵蚀修改。[12]

World Machine 的文档从生产工具角度说明，erosion filter 用雨水和流水模拟数千到数百万年的风化，能为人工地形增加细节和真实感；它还会输出 flow、wear、deposition 等 mask，用于材质贴图。[13]

对当前项目，不建议一开始实现完整物理水蚀。更实际的是：

- 先在 200x200 或 256x256 高度网格上离线/初始化运行 10k-50k 个水滴。
- 每个水滴最多走 20-60 步。
- 输出侵蚀后的高度，以及 flow/deposition 两张辅助图。
- 渲染时仍使用现有 Three.js mesh 和 shader。

### 4.5 Thermal Erosion（热蚀 / 崩塌）

热蚀模拟坡面因重力、冻融、松散物质滑落而趋于稳定。常见简化模型是 talus angle：当相邻格子的坡度超过阈值，就把高处材料搬到低处。

作用：

- 去掉过尖的噪声刺。
- 形成碎石坡、山脚堆积、较自然的坡面。
- 与水蚀互补：水蚀切沟，热蚀稳定坡。

对当前项目，热蚀比水蚀更容易实现，可作为第二阶段。

### 4.6 Tectonic Uplift + Fluvial Erosion

Cordonnier 等人的 “Large Scale Terrain Generation from Tectonic Uplift and Fluvial Erosion” 明确提出，大尺度景观来自构造抬升与水文侵蚀的组合，并通过构造抬升与河流侵蚀生成视觉可信的地形。[14]

这类方法比单纯噪声更接近真实地貌：

- 山脉不是随机峰，而是构造带抬升。
- 河流不是随机线，而是沿坡面汇流、切割谷地。
- 高度图可以从河网、分水岭、流域结构反推。

但它实现成本较高，更适合未来版本或离线生成器。

### 4.7 真实 DEM 与混合生成

如果追求“真实地形质感”，可直接采样真实 DEM。NASA SRTM 项目生成了近全球高分辨率数字高程模型，NASA/JPL 页面称其产生了地球陆地表面的近全球 DEM。[15] Copernicus DEM 也提供全球和欧洲数字高程模型数据集。[16]

现实数据可用于三种方式：

- 直接导入高度图作为地形。
- 从真实 DEM 中统计坡度、曲率、河谷宽度，用作程序生成参数参考。
- 混合真实地形 patch 与程序噪声，生成“像某地但不是某地”的地貌。

对当前项目，可以先下载几张真实山地 DEM，高度归一化后与程序结果对比：坡度分布、等高线密度、谷地连通性会非常直观。

### 4.8 机器学习与扩散模型

近年的 Terrain Diffusion、TerraFusion、MESA 等研究尝试用扩散模型或遥感数据生成地形。优点是视觉真实度高、可接受文本/草图/气候条件；缺点是实现复杂、依赖数据与模型，且实时无限生成仍有工程挑战。

对当前项目，机器学习不应作为近期路线。更现实的用法是把真实 DEM 或 AI 生成 heightmap 当作参考样本，帮助调参。

## 5. 推荐给当前项目的技术路线

### 阶段 A：不改架构，升级高度函数

目标：在 `TerrainDataGenerator.js` 中替换 `getHeight()` 组合逻辑。

建议公式：

```js
height =
  continent * 18
  + mountainMask * ridgedMountains * 70
  + hills * 12
  + detail * 3
  - valleyMask * 18;
```

关键点：

- `continent`：低频噪声，决定整体高低。
- `mountainMask`：更低频且经过阈值/smoothstep，决定哪里允许长山脉。
- `ridgedMountains`：ridged multifractal，专门生成山脊。
- `valleyMask`：可先用反向 ridged 或 flow approximation 近似谷地。
- `detail`：小振幅噪声，只做表面粗糙，不决定大地形。

### 阶段 B：加入 domain warping

在所有主噪声采样前加入坐标扭曲：

```js
const warpX = noise(x * 0.006, z * 0.006, seed + 11);
const warpZ = noise(x * 0.006, z * 0.006, seed + 29);
const wx = x + warpX * 35;
const wz = z + warpZ * 35;
```

建议先只对山脉和谷地采样使用 warp，避免整体大陆边缘过度扭曲。

### 阶段 C：高度图后处理侵蚀

把当前“每个顶点实时调用 `getHeight(u, v)`”改成“先生成高度网格，再查询插值”。这样可以在网格上运行侵蚀：

1. 生成 256x256 heightmap。
2. 运行轻量 hydraulic erosion。
3. 运行 2-5 轮 thermal erosion。
4. 计算 `minH/maxH/slope/flow/deposition`。
5. Three.js mesh 从 heightmap 采样。

### 阶段 D：把派生图层用于视觉

当前 shader 只按高度取色。更自然的上色应结合：

- 高度：雪线、低地、山顶。
- 坡度：陡坡裸岩，缓坡草地。
- flow：沟谷更暗、更湿。
- deposition：谷底、冲积扇偏黄/浅色。

这会让等高线图不仅“线条自然”，整体地貌也更可信。

## 6. 推荐实现优先级

| 优先级 | 技术 | 成本 | 视觉收益 | 建议 |
|---|---|---:|---:|---|
| P0 | domain-warped fBm | 低 | 高 | 立即做 |
| P0 | ridged mountain mask | 低 | 高 | 立即做 |
| P1 | heightmap 缓存 | 中 | 中 | 为侵蚀铺路 |
| P1 | 简化 thermal erosion | 中 | 中 | 先于水蚀 |
| P2 | 粒子水蚀 | 中高 | 很高 | 做初始化后处理 |
| P2 | flow/deposition 可视化 | 中 | 高 | 配合 shader |
| P3 | 河网/流域生成 | 高 | 很高 | 后续版本 |
| P4 | DEM/ML 混合 | 高 | 高 | 研究型功能 |

## 7. 可落地的模块重构建议

建议把 `TerrainDataGenerator.js` 拆成以下职责，但不一定马上拆文件：

```txt
TerrainDataGenerator
├─ noise samplers
│  ├─ fbm()
│  ├─ ridged()
│  └─ domainWarp()
├─ masks
│  ├─ continentMask()
│  ├─ mountainMask()
│  ├─ valleyMask()
│  └─ moistureMask()
├─ height synthesis
│  └─ composeHeight()
├─ post process
│  ├─ hydraulicErosion()
│  └─ thermalErosion()
└─ derived maps
   ├─ calculateSlope()
   ├─ calculateFlow()
   └─ calculateStats()
```

短期最小改动版：保留 `getHeight(u, v)`，只新增 `fbm`、`ridged`、`warp2D` 三个内部方法。

中期自然版：新增 `generateHeightmap()`，让 `ContourVisualizer` 从缓存高度图读高度。

## 8. 结论

如果目标是“肉眼不再一眼看出随机生成”，最有效的路线不是追求某一个神奇噪声，而是采用 Minecraft 与专业地形工具共同体现出的分层思想：

```txt
宏观地貌控制
→ 山脉/谷地/海盆遮罩
→ 扭曲采样
→ ridged + fBm 细化
→ 水蚀/热蚀后处理
→ slope/flow/deposition 驱动颜色
```

当前项目规模很小，反而适合快速实验。建议下一步先实现 **domain-warped ridged fBm**，再把高度生成从“逐点函数”升级为“缓存 heightmap”，最后加入简化侵蚀。这样既保留浏览器实时性，又能显著提升自然感。
