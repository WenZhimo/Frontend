# 晦明可玩版

这是一个零构建的静态热座双人版本，规则与素材来自 `https://github.com/yoli-mi/huiming`。

## 打开方式

直接用浏览器打开 `index.html` 即可游玩，不需要安装依赖或启动服务。

## 已实现

- 5x5 牌阵，中心固定 Joker，四花色各 6 张随机排布。
- 明置取牌、暗取能力、Joker 明置限制、取牌后翻动上下左右四邻。
- 每位玩家每局一次常规放牌，支持选择明置或暗置。
- 热座隐私：暗取牌只在拥有者回合和结算后显示，对手视角显示为未知牌。
- 只剩一张且无人胜利时进入续局摆牌；第二轮仍无胜负时比较最多同花色数量。
- 纸面、暗黑、墨印、翠玉四套主题，可随时切换。
