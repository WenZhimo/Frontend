# 季节风模拟：压力驱动与经度变化 ITCZ

## 背景

该计划为世界造山加入由高低压系统驱动的季节风。ITCZ（热带辐合带）不是固定纬度，而是沿经度跟随“热赤道”：在海洋上接近赤道，在大陆上可向夏半球移动 15-20 度，从而形成季风和季节性风向反转。

## 算法

1. **计算热赤道 / ITCZ 纬度**：按经度采样，在 -30° 到 +30° 间寻找有效加热最大值，再用周期样条平滑。
2. **构建压力场**：叠加 ITCZ 低压、副热带高压、副极地低压、极地高压、陆海热力修正、高程气压效应、噪声和平滑。
3. **计算压力梯度**：把邻居位移投影到局部东/北切平面，用最小二乘估计梯度。
4. **压力转风**：气压梯度力指向低压，科里奥利参数随 `sin(lat)` 自然变号，因此跨赤道季风不需硬编码。
5. **归一化**：使用 95 分位数把风速缩放到 0-1。

## 坐标约定

- 地图投影使用 Y 轴为极轴。
- 纬度 `lat = asin(y)`，经度 `lon = atan2(x, z)`。
- 东向为 `(z, 0, -x)` 归一化，北向为 `cross(position, east)`。

## 验证

- 夏季压力：ITCZ 蓝色低压带在海洋附近贴近赤道，在大陆上向夏半球偏移。
- 冬季压力：ITCZ 南移，北半球大陆出现热高压。
- 风箭头应自然显示信风、西风和跨赤道季风。
- 同一种子应得到完全相同的压力和风数组。
