# 世界造山（World Orogen）

一个浏览器端程序化行星生成器，用构造板块、高程建模、侵蚀、气候与交互编辑生成可信的类地行星。项目使用原生 ES 模块，无需构建步骤。

[![在线体验](https://img.shields.io/badge/在线体验-orogen.studio-brightgreen)](https://orogen.studio/) ![Three.js](https://img.shields.io/badge/Three.js-0.160.0-blue) ![无需构建](https://img.shields.io/badge/构建-无需-green)

## 项目哲学

世界造山是面向行星概念设计的工具，不是严格地球物理模拟器。它服务于项目早期：你需要一个看起来真实、能快速迭代、可继续用于游戏、小说、桌游或美术流程的星球。

科学性不是装饰。真实构造启发的板块碰撞、压力驱动风场、洋流、降水、温度与柯本气候分类，是让结果第一眼可信的基础。原则是可信优先于严格，审美和创作速度优先于完美物理精度。

## 指导原则

1. **艺术吸引力**：输出应有视觉趣味，并受真实科学启发。
2. **易用与效率**：界面应直观，生成应快速，不为真实性牺牲可用性。
3. **科学可信度**：地形、构造和气候要有合理解释，但不要求严格仿真。

## 功能

- **Fibonacci 球面网格**：通过 Delaunay 三角剖分生成 Voronoi 单元。
- **构造板块模拟**：板块种子、扩张、边界平滑、碎片重连和海陆分配。
- **边界分类**：根据相对运动识别汇聚、张裂、转换边界，并加入俯冲与超板块分组。
- **高程生成**：山脉、海沟、海底、裂谷、弧后盆地、热点火山、岛弧、陆架与海岸细节。
- **地形后处理**：地形扭曲、双边平滑、冰川侵蚀、水力侵蚀、热侵蚀、山脊锐化和土壤蠕动。
- **季节风场与洋流**：压力带、ITCZ、陆海热力差、科里奥利偏转、表层环流和热量输送。
- **气候与生态显示**：夏冬季降水、温度、雨影、柯本气候和类卫星生物群系颜色。
- **时间轴与快照**：捕获、恢复、步进、播放和对比世界状态。
- **轻量地质记忆**：洋壳年龄、裂谷阶段、旧造山、转换记忆、断裂带记忆、沉积记忆和海洋连通性诊断层。
- **文明 MVP**：宜居性、淡水、农业潜力、通行成本等环境输入驱动人口、迁徙、聚落、文化、语言和政体。
- **历史导出**：导出文明摘要、时间线、谱系、迁徙廊道、遗迹和压力信号。
- **高度图导入**：导入 2:1 等距圆柱黑白高度图，并自动计算气候。
- **地图导出**：导出彩色地形、卫星图、柯本气候图、16 位高度图、陆地高度图和陆地掩膜，宽度最高 65,536 像素。
- **可分享行星码**：种子、滑块和板块编辑可编码进 URL。

## 快速开始

ES 模块需要本地 HTTP 服务。任选一种方式：

```bash
# Python
python3 -m http.server 8000

# 或 Node.js
npx serve .
```

然后在浏览器打开 `http://localhost:8000`。无需安装依赖，也无需构建。

点击 **生成新世界** 创建随机行星。按钮状态含义：

- **生成新世界**：新种子生成完整行星。
- **重建**：保留种子和板块编辑，只用当前细节/地形参数重算。
- **重新生成**：板块、大陆或海陆比例变化后，创建新的构造格局。

## 导航

- **生成**（`/`）：板块、侵蚀、气候、时间轴和文明层。
- **导入高度图**（`/import`）：导入等距圆柱高度图，投影到 3D 球体并计算气候。

## 控件概览

### 塑造世界

| 控件 | 范围 | 默认 | 说明 |
|---|---:|---:|---|
| 细节 | 5,000-2,560,000 | 204,000 | 球面 Voronoi 单元数，只影响显示分辨率。 |
| 不规则度 | 0-1 | 0.75 | Fibonacci 点位扰动强度。 |
| 板块 | 4-120 | 80 | 构造板块数量。 |
| 大陆 | 1-10 | 4 | 目标陆块数量。 |
| 起伏 | 0-0.5 | 0.40 | 地形分形噪声幅度。 |
| 大陆大小差异 | 0-1 | 0.35 | 控制大陆面积是否相近。 |
| 陆地覆盖率 | 0-1 | 0.30 | 星球陆地比例；高陆地比例会抑制降水。 |

### 地形、气候和导出

- 地形雕刻包含地形扭曲、平滑、冰川侵蚀、水力侵蚀、热侵蚀和山脊锐化，可单独重新应用。
- 气候控件提供温度和降水全局偏移，高细节下会按需延迟计算气候。
- 可视化包含球体/地图视图、地形/卫星图/气候/高度图主图层、检查图层、线框、板块、自动旋转和经纬网。
- 导出类型包括彩色地图、卫星图、柯本气候图、完整高度图、陆地高度图和陆地掩膜；批量导出会自动补算气候。

### 时间轴、文明与历史

- 演化时间轴支持播放、步进、捕获快照、恢复快照、删除快照和上一快照对比。
- 文明 MVP 可播种人口群体，并按年份推进迁徙、定居、农业化、文化/语言分裂和政体形成。
- 历史导出可生成当前文明摘要或历史时间线，并导出 JSON 或 Markdown。

## 工作原理

生成管线概览：Fibonacci 球面点 -> Delaunay / Voronoi 网格 -> 粗板块 -> 海陆分配 -> 高分辨率投影 -> 板块运动和边界分类 -> 构造高程 -> 地形后处理 -> 风、洋流、降水、温度、柯本气候 -> 球体与地图渲染。

关键算法包括确定性 PRNG、3D Simplex 噪声、调和均值距离混合、球面地形扭曲、密度俯冲、BFS 距离场、高斯热点隆起、优先洪泛排水和流功率侵蚀。
