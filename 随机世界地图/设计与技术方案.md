# 随机世界地图生成器 — 可行性分析与技术设计方案

> 目标：在浏览器中运行一款过程化星球地图生成器。给定随机种子与一组初始参数，生成原始星球，并按可调时间步长逐年/逐百年/逐千年演化，最终可查看每个地点的气候、地形、水文、资源等信息。
> 本文档基于真实基准测试给出可行性结论与完整技术方案。

---

## ★ 设计定位与核心原则（首要）

**最终交付物是一张物理上自洽的完整世界地图**（含山脉、平原、沙漠、海洋、河流、冰原等地形，并标注气候/资源），用于架空世界观创作。一切功能（参数调节、演化模拟、3D 地球、导出）都为这张地图服务。

「过程化」在本项目中的含义不是「随机生成」，而是 **「让每一处细节出现在物理定律要求的位置」**。因此确立一条不可违背的原则：

> **零直接放置原则**：任何地貌（沙漠、雨林、山脉、河流…）都不允许被随机摆放到地图上。每个地貌必须由其物理成因链推导得出——是板块运动、大气环流、水文、轨道参数共同作用的结果。随机性只用于初始扰动与量子级涨落，不用于决定「哪里有什么」。

> **海陆后置原则**：不先固定“这里是大陆、那里是海洋”。生成器先产生板块、地壳类型、地壳厚度、地壳年龄、抬升、侵蚀和沉积等地质原因，最后由统一海拔场与海平面切分出当前大陆和海洋。海陆是结果，不是输入。

这两条原则把项目从「会动的模拟器」重新定位为「物理一致性引擎」：模拟是手段，合理地图是目的。下文 §A「因果一致性链」给出每类地貌的成因链，§B 给出已验证的气候模型要点，§C 重新定义交付物与导出。

## 1. 可行性结论（已用基准验证）

核心顾虑是「浏览器能否实时模拟一个含板块、气候、水文的网格星球」。我在 Node/V8（与 Chrome 同一 JS 引擎）中实现了关键算法内核并计时，结果如下：

| 网格分辨率 | 单元数 | 地形生成(一次性) | 板块分配(一次性) | 构造/步 | 气候/步 | 水文/步(优化) | 单步合计 |
|---|---|---|---|---|---|---|---|
| 256×128 | 32k | 9 ms | 6 ms | 5 ms | 1.5 ms | 5.7 ms | ~12 ms |
| 512×256 | 131k | 15 ms | 8 ms | 6 ms | 1.7 ms | 10.4 ms | ~18 ms |
| 1024×512 | 524k | 41 ms | 28 ms | 22 ms | 2.8 ms | 40.8 ms | ~66 ms |

> 60 FPS 帧预算 ≈16 ms，30 FPS ≈33 ms。Canvas `putImageData` 绘制 131k 像素 <2 ms，可忽略。

**关键发现：**
- **默认 512×256（13 万格）单步演化约 18 ms**，单线程即可接近 60 FPS；一次 500 步的完整星球史约 9 秒。
- **水文（河流汇流）是首要瓶颈**：朴素实现用 `sort` 做拓扑排序（131k→47ms，524k→467ms）。改用「按量化高程的桶排序」O(N) 后，131k→10ms、524k→41ms，瓶颈基本消除。
- **1024×512（52 万格）单步 ~66 ms**，放进 Web Worker 后台计算完全可行，主线程仍可流畅渲染与交互。
- **确定性可复现**：种子化 PRNG（mulberry32）+ 同参数 → 同一星球。

**结论：方案完全可行。** 推荐默认 512×256 模拟分辨率 + Web Worker 后台演化 + Canvas 2D 主图 + Three.js 3D 地球展示。下文给出完整设计。

## 2. 总体架构

完全客户端、无后端、打开 HTML 即可运行。分三层：

```
┌─────────────────────────────────────────────┐
│  UI 层 (main thread)                        │
│  参数面板 · 时间轴 · 图层开关 · 图例 · 悬停信息 │
└───────────────┬─────────────────────────────┘
                │ 参数/指令
┌───────────────▼─────────────────────────────┐
│  渲染层 (main thread)                       │
│  Canvas 2D 多图层 · Three.js 3D 地球        │
└───────────────▲─────────────────────────────┘
                │ transferable ArrayBuffer (零拷贝)
┌───────────────▼─────────────────────────────┐
│  模拟层 (Web Worker)                        │
│  演化引擎 → 地形/板块/气候/水文/大气/撞击/资源 │
└─────────────────────────────────────────────┘
```

数据流：UI 设参数 → Worker 按种子+参数生成并逐步演化 → 每步把网格 Typed Array 通过 `postMessage` 的 transferable 列表零拷贝传回主线程 → 渲染层绘制。Worker 与主线程用 `Float32Array`/`Int32Array` 表达所有网格字段，避免序列化开销。

## 3. 星球与地图表示

### 3.1 投影与网格

采用 **等距圆柱投影（Equirectangular）2D 网格** 作为模拟与存储表示：
- `x` 轴对应经度（0..2π），**环绕（wrap）**以模拟球面闭合；
- `y` 轴对应纬度（-π/2..π/2），两极为边界；
- 每格存储一组物理字段（高程、温度、降水、板块、流速、资源…）。

理由：实现简单、邻域查询 O(1)、x 方向环绕天然贴合球面、与 3D 球面纹理直接对应。极区面积拉伸的失真对「气候/资源展示」可接受；若需更高保真，升级路径为立方球面（Cubed-sphere）或二十面体细分网格（见 §12）。

**地形接缝处理**：2D 噪声在 x=0/2π 处会出接缝。采用 **3D 单纯形噪声在单位球面上采样**（地形生成仅一次性，开销可接受），保证全球无缝。

### 3.2 世界状态数据模型

每个网格维护如下 Typed Array（以 512×256 为例，单字段 512KB）：

| 字段 | 类型 | 含义 |
|---|---|---|
| `elev` | Float32 | 高程（负=海洋） |
| `plate` | Int32 | 所属板块 id |
| `pvx/pvy` | Float32 | 板块速度 |
| `temp` | Float32 | 年均温（℃） |
| `precip` | Float32 | 年降水（mm） |
| `flow`/`acc` | Int32/Float32 | 流向 / 汇流累积 |
| `biome` | Int8 | 生物群落 id |
| `ice` | Float32 | 冰盖厚度 |
| `atmO2` | Float32 | 局地含氧（可全局标量） |
| `resMineral`/`resWater`/`resHydro` | Float32 | 矿产/淡水/烃类资源潜力 |
| `impactAge` | Int32 | 最近撞击距今（用于坑迹） |

外加全局标量：海平面、水储量、大气厚度、含氧量、星龄、太阳距离、卫星参数、自转/倾角等。

### 3.3 确定性

所有随机源统一走种子化 PRNG（mulberry32，可换 xoshiro128++）。用户可见的种子为任意字符串 `seedText`（可包含中文、空格、符号等），模拟前先用稳定字符串哈希（如 UTF-8/FNV-1a）映射为 `seedUint32`，再交给 PRNG。`seedText` + 参数全集 → 唯一星球。保存/分享/复现时保留原始 `seedText`，而不是只保存派生数字。

## 4. 模拟模型

演化引擎每步依次调用下列子模型。各模型均设计为「足够合理、可参数化、单步低成本」。

### 4.1 地壳初始场与海拔派生

- 初始噪声不直接生成最终海陆 mask，而是生成 **初始地壳亲和度**：哪些区域更倾向厚陆壳、薄洋壳、古老克拉通或弱带。
- 板块、地壳类型、地壳厚度、地壳年龄、密度、弱带、沉积和造山根共同决定基础海拔场。
- 多倍频噪声（fBm）和 domain warping 只作为自然扰动，用于打破规则轮廓、增加粗糙度和区域差异，不用于直接指定“这里有山/这里有海”。
- 最终 `elev` 由地壳浮力、构造抬升/下沉、沉积/侵蚀和多尺度细节统一派生。
- 海平面由全局水储量或目标水量求解，最后切出当前大陆、浅海、大洋和内陆湖。**海陆比例是派生结果，不是初始硬编码。**

### 4.2 板块构造（地壳运动）

- **板块划分**：撒 K 个种子点，多源 BFS（flood-fill）做 Voronoi 式分配（基准中已验证，131k 格 8 ms）。板块数 K 可参数化。
- **运动**：每板块一个速度向量，大小由 **地壳运动烈度** 缩放。
- **大结构骨架**：板块决定地貌骨架。汇聚边界生成山脉、岛弧、海沟和高原；张裂边界生成洋中脊、裂谷和长期张裂后的狭长海；转换边界生成断层、线性山谷和局部抬升/沉降；古老大陆内部主要表现为低缓丘陵、盆地和平原。
- **漂移实现约束**：板块漂移不是把高程栅格整图平移/重采样。真实板块近似刚性运动，板块内部相对稳定，主要变形集中在边界；大陆壳随所在板块运动，离散边界生成新洋壳，汇聚边界消耗洋壳并造山。因此工程实现应使用板块局部坐标/板块携带的地壳场来表现大陆随板块移动，构造起伏单独累积并侵蚀，禁止用反复像素平流来“拖动大陆”，否则大时间步会产生不真实的扇形拖影、锯齿条带和抽象化地形。
- **海岸线约束**：大陆/海洋基底必须来自连续的地壳场，不得按当前板块多边形边界重新裁剪或重采样，否则海岸线会沿板块边界形成不自然的直线。内陆离散边界只生成裂谷、断陷盆地和局部低地；在水文/湖泊系统实现前，禁止让两个陆内板块反向移动就凭空生成规则海洋或矩形内陆湖。
- **构造地形分层**：活动边界的海岭、海沟、断层凹凸是“当前边界地形”，应随边界移动而重算；长期保留的 `relief` 只用于大陆碰撞造山、稳定陆缘抬升等会留下地质记录的过程。禁止把洋中脊/海沟/临时边界隆起直接累积进持久高程层，否则移动边界会像刷子一样在海底留下高山拖尾、半深半浅湖和扇形湖。
- **边界形态约束**：板块边界不应由纯 Voronoi/BFS 直线决定。应维护稳定的地壳弱区场 `weakness`，板块归属用带代价的多源扩张生成，使边界倾向沿弱区、陆缘和旧断裂带弯曲。构造作用应使用 `boundaryInfluence` 形成有宽度的边界带；远离活动边界的旧构造，特别是海底旧构造，应快速侵蚀/衰减，避免数亿年后积累成平行划痕。
- **多尺度扰动**：规则感通常来自纯 Voronoi、网格邻域和过度确定性的更新。板块边界、山带轴线、盆地边缘和海岸线应叠加 domain warping、弱带偏移、断续性和多尺度地形层；噪声负责“自然变化”，不负责“地貌成因”。
- **边界应力**：逐格比较与邻格的板块及相对速度。会聚（相对速度朝向边界）→ 俯冲/抬升（造山、火山）；离散 → 张裂、新生洋壳（洋中脊）；走滑 → 断层。
- **高程更新**：应力乘以烈度与时间步累加到 `elev`；山脉随时间侵蚀（指数衰减），沉积物填入盆地/海洋。
- **资源耦合**：俯冲带/造山带/火山 → 富集金属矿脉；新生洋壳 → 基性岩矿。

### 4.3 气候（详见 §B：降水必须双路解耦）

- **温度** = f(纬度余弦日照 × 太阳距离⁻² + 轴倾角季节 + 大气温室项 − 高程递减率 − 冰反照率反馈 + 海洋热容调节)。
- **风**：按纬度简化三圈环流（哈德利/费雷尔/极地）+ 自转科里奥利 → 每纬度盛行风向。
- **降水**：风自海洋携湿，遇山地抬升致雨（雨影效应）；按纬度带分布（赤道辐合带多雨、副热带干燥、温带、极地干燥）。基准已验证 O(W·H) 单步 1.7 ms（131k）。
- **海洋流**：简化环流影响沿岸温度。
- **冰盖**：极地/高海拔低于冰点 → 结冰 → 反照率升高 → 正反馈降温。
- **生物群落**：由温度+降水分类（Köppen/Whittaker 式）→ 雨林/草原/沙漠/苔原/冰原等，即「每地气候」标注。

### 4.4 水文

- 海平面由全局水储量决定。
- **D8 最陡流向** + **桶排序汇流累积**（基准优化版，131k 仅 10 ms）→ 超阈值即河流。
- 局地极小值 → 内流盆地 → 湖泊（逐步填充至溢流）。
- 水储量变化（含水彗星撞击增水、薄大气蒸发失水）→ 海平面漂移 → 海岸线演变。

### 4.5 大气

- **大气层厚度** → 表面气压 → 沸点（薄大气使水低温沸腾、星球失水）、温室效应（适中增温、过厚如金星失控）、辐射屏蔽（厚大气烧蚀更多小天体、削弱撞击）。
- **含氧量** → 宜居度、火险阈值、矿物氧化（铁矿）、大气颜色。主要作为「宜居指数」与资源指示。
- 大气对气候的反馈以参数项注入温度与蒸发模型。

### 4.6 陨石撞击

- 每步按 **撞击概率 × 时间步** 采样泊松分布得撞击数；每个撞击：
  - **地点**按 **撞击地点分布** 采样（均匀/聚集带/极区偏多/赤道带/历史坑区密集）；
  - **大小**按幂律分布；
  - **类型**按比例在「含水彗星 / 含矿陨石」间分配。
- **效果**：
  - 坑（中心下凹 + 喷溅环抬升 `elev`）；
  - 气候冲击（扬尘 → 数步「撞击冬天」全局降温）；
  - 含水彗星 → +水储量、局地增湿；
  - 含矿陨石 → 坑址富集矿产 `resMineral`；
  - 巨型撞击 → 抛失部分大气（大气变薄）。

### 4.7 轨道参数

- **太阳距离** → 日照 ∝ 1/d²，设定基础温度与宜居带；影响冰盖范围与蒸发。
- **卫星个数/质量** → 潮汐力（潮汐加热=微量构造/热输入、沿岸潮汐）、自转轴稳定度（卫星多→气候更稳定、季节摆动小）、潮汐锁定趋势。
- **自转速度** → 昼长、科里奥利、风强。
- **轴倾角** → 季节强度。

### 4.8 资源

资源由地质历史累积，作为可叠加图层展示：
- **金属矿**：造山带/俯冲带/火山/含矿陨石坑（与 §4.2/4.6 耦合）。
- **烃类（油/煤）**：宜居气候下沉积盆地经长时间埋藏（需气候+时间条件）。
- **淡水**：河流、湖泊、冰盖（§4.4）。
- **稀土/基性矿**：火成岩省、洋壳。
每格维护资源潜力场，随事件累加，按浓度分级着色。

### 4.9 合理性检查与局部修复

很多不合理地形不应靠无限演化“熬过去”，而应由诊断器发现并局部修复。后处理不是随机美化，而是验证物理链条是否闭合：

- **水文检查**：河流必须总体向低处流；大湖需要有入水、出水、封闭盆地或蒸发解释；无来源的深水坑应被沉积填平或标为异常事件。
- **地形检查**：山脉不应棋盘状散布；旧山带应低缓、宽、断续；当前活动山带应与汇聚边界或火山链有因果关系。
- **海岸检查**：海岸线不应沿板块边界硬切；应存在大陆架、半岛、海湾、岛链和浅海过渡。
- **气候检查**：沙漠通常应由纬度下沉带、雨影、寒流或内陆性解释；高海拔应影响温度、降水、河流和冰盖。
- **构造检查**：海底长直旧边界残影、规则矩形海盆、无水文来源内陆湖、异常孤立高山都应进入诊断报告，并由侵蚀、沉积、平滑或事件解释局部修复。

## 5. 参数体系

用户可调参数（默认值与影响）。所有参数与 `seed` 共同构成可保存/分享的「星球配方」。

| 参数 | 范围(建议) | 默认 | 作用 |
|---|---|---|---|
| 随机种子 | 任意字符串 | 随机短语 | 决定全部过程化生成，可复现；内部稳定哈希为 32 位 PRNG 种子 |
| 初始含水量 | 0–100% | 50% | 设海平面/海陆比、气候海洋调节、河流 |
| 含氧量 | 0–30% | 21% | 宜居度、火险、矿物氧化、大气色 |
| 地壳运动烈度 | 0–5× | 1× | 板块速度/造山/火山/矿产富集速率 |
| 板块数 | 4–40 | 12 | 大陆破碎度 |
| 陨石撞击概率 | 0–高 | 中 | 每步撞击数（泊松率） |
| 陨石类型 | 彗星/陨石/混合 | 混合 | 含水彗星增水 vs 含矿陨石增矿 |
| 撞击地点分布 | 均匀/聚集/极区/赤道/坑区 | 均匀 | 撞击空间分布 |
| 大气层厚度 | 0.001–100× | 1× | 温室/气压/沸点/辐射屏蔽/撞击烧蚀 |
| 太阳距离 | 0.3–3 AU | 1 AU | 日照、基础温度、宜居带、冰盖 |
| 卫星个数 | 0–5 | 1 | 潮汐、轴稳定、气候稳定 |
| 卫星总质量 | 0–5×月 | 1× | 潮汐强度 |
| 自转速度 | 0.1–10× | 1× | 昼长、科里奥利、风 |
| 轴倾角 | 0–90° | 23.5° | 季节强度 |

## 6. 演化时间引擎

- **时间步可配**（1 年 / 100 年 / 1 千年 / 1 万年 / 1 百万年）。地质过程（板块、撞击）以 kyr–Myr 为宜；短时气候事件可细到年。
- **全星球史**默认跑数百步（如 1 kyr×500 = 50 万年，或 1 Myr×500 = 5 亿年），按上节基准 9 秒内完成。

- **分层更新频率**（性能关键）：
  - 地形高程、海平面：每步；
  - 气候（温/降水/风）：每步；
  - 水文（河流）：高程变化超阈值或每 N 步重算（河流响应慢，省算力）；
  - 资源、生物群落：每步或每几步。
- **事件日志**：记录大撞击、超级火山、海平面突变等里程碑，时间轴上可点阅。

## 9. 性能策略

1. **分辨率分档**：256×128 预览、512×256 默认（单步 ~18 ms 接近 60 FPS）、1024×512 高质（Worker ~66 ms/步）。
2. **Web Worker 后台演化**：主线程仅渲染与交互；网格用 transferable 传递。
3. **桶排序水文**：O(N) 替代 O(N log N)（基准已验证 10× 提速）。
4. **惰性重算**：河流等慢变量按阈值/周期重算。
5. **关键帧快照**：时间轴拖拽回看用快照，不重算历史。
6. **模拟-渲染分离**：可在低于渲染分辨率下模拟，渲染上采样。

## A. 因果一致性链（核心设计）

「零直接放置原则」要求每类地貌都有一条可追溯的成因链。下表是本项目所有地貌/资源的成因映射——这是整个引擎的设计骨架，也是验收标准：**生成结果必须满足这些因果关系**。

| 地貌/要素 | 物理成因链 | 由哪些参数驱动 |
|---|---|---|
| **山脉** | 板块汇聚边界 → 俯冲/碰撞 → 地壳褶皱抬升；或热点火山链 | 板块数、地壳运动烈度 |
| **平原/高原** | 板块内部稳定克拉通；或长期沉积盆地；高原=抬升的稳定地块 | 板块数、烈度、时间 |
| **海岭/洋中脊** | 板块离散边界 → 新生洋壳 | 板块数、烈度 |
| **海沟** | 板块俯冲带 | 板块数、烈度 |
| **沙漠** | (1)副热带高压下沉带(±30°) (2)山脉雨影(背风坡) (3)寒流西岸 | 大气、太阳距离、自转(决定环流)、山脉位置 |
| **雨林** | 赤道 ITCZ 对流性降水 + 全年高温 | 太阳距离、含水量、自转 |
| **草原/稀树草原** | 干湿过渡带（雨林↔沙漠之间、季风边缘） | 同上 |
| **温带森林** | 中纬西风带海洋性气候（迎风海岸）；极锋降雨带 | 自转、含水量、海陆配置 |
| **泰加林(寒带林)** | 高纬寒冷但湿润 | 太阳距离、自转 |
| **冰原/冰川** | 极地/高海拔低于冰点 + 反照率正反馈 | 太阳距离、大气厚度、含水量 |
| **河流** | 沿高程最陡流向(D8)汇流，累积流量超阈值 | 含水量、地形、气候 |
| **湖泊** | 内流局地极小值蓄水至溢流 | 含水量、地形 |
| **季风** | 海陆热力差异 + 信风季节性转向 | 含水量、自转、海陆配置 |
| **金属矿** | 俯冲带/造山带/火山/含矿陨石坑 | 烈度、陨石类型与分布 |
| **烃类(油/煤)** | 宜居气候沉积盆地 + 长时间埋藏 | 气候、含氧量、时间 |
| **淡水** | 河流/湖泊/冰盖 | 含水量、气候 |
| **撞击坑** | 陨石按概率×类型×分布采样 | 撞击概率、类型、地点分布 |

**已用原型验证（4/4 通过）**：在 `prototype/causal5.js` 中，给定一条山脉 + 三圈环流，下列地貌全部从物理涌现而非摆放——
- ✅ **雨影**：西风带山脉迎风坡降水 160 vs 背风坡 41（比 0.26），背风侧形成沙漠
- ✅ **纬度带**：赤道降水 73 vs 副热带 7，赤道雨林、副热带沙漠
- ✅ **沙漠集中**：500 格沙漠中 377 在副热带、123 在温带雨影区，赤道 0 格沙漠
- ✅ **西岸寒流沙漠**：副热带西岸降水 0.2 vs 东岸 0.9（阿塔卡马/纳米布型）

这证明「地貌从物理涌现」在浏览器中可行，且模型可调到与真实地球图样一致。

## B. 气候模型关键设计（原型验证的核心教训）

气候是地貌合理性的命门。原型迭代暴露了一个非平凡要点，必须写进设计：

**降水必须解耦为两路独立机制**：
1. **纬度对流降水（全球环流驱动）**：ITCZ 赤道辐合增雨、极锋带增雨、副热带哈德利下沉减雨。它**不依赖海岸距离**，因此能让赤道内陆也成雨林（如亚马逊、刚果）。若不解耦，纯海洋平流会让赤道内陆干成沙漠——违背现实。
2. **海洋平流降水（海岸/地形驱动）**：风自海洋携湿，遇山地抬升致雨、背风雨影。它负责雨影、海岸湿润、寒流西岸干燥。

二者相加得总降水。`precip = advective(受水汽上限约束) + convective(纬度函数)`。原型 v1→v4 的失败→成功正是这一解耦：v1 纯平流导致赤道内陆沙漠；v4 解耦后赤道整条雨林带涌现。

其余气候要点（均已在原型中体现）：
- **温度** = 纬度日照(∝1/太阳距离²) − 高程递减率 + 大气温室项 − 冰反照率反馈；
- **风** = 三圈环流按纬度给盛行风向（信风东→西、西风西→东、极地东风），决定水汽来源海岸；
- **寒流** = 副热带西海岸蒸发弱 + 冷水 → 西岸沙漠（阿塔卡马/撒哈拉西缘/纳米布）；
- **生物群落** = 温度×降水查表（Köppen/Whittaker 式），非随机。

> 工程含义：气候模型不能写成「噪声场查表」，必须是「纬度函数 + 平流模拟」的物理组合。这是保证沙漠/雨林出现在正确位置的关键。

### C.2 交互（服务于创作，非产品本身）

参数面板与演化时间轴的作用是**让作者在「世界观空间」中导航**：调含水量得到水世界或旱地、调烈度得到破碎群岛或超级大陆、调太阳距离得到冰封或灼热星球、调陨石参数留下创伤史。**物理定律始终约束结果自洽**——作者只能改变「初始条件与力」，不能直接指定「哪里是沙漠」。这正是「过程化=合理」的体现。

### C.3 后续：星球粗略模型导出

- **高度图**（等距圆柱 PNG/EXR）→ 可导入 Blender/World Machine；
- **球面网格**（经纬度网格 OBJ，顶点位移按高程）→ 轻量 3D 模型；

## D. 修订后的实施重点

按「物理合理性优先」重排优先级（原 §11 路线图的精炼）：

1. **地形成因**（板块划分→汇聚造山/离散成岭→侵蚀沉积）——先保证山脉在海岭/俯冲带，而非随机。
2. **海陆后置**（地壳厚度/年龄/沉积/抬升→海拔→海平面切分）——保证大陆和海洋是地质结果，而不是初始 mask。
3. **多尺度扰动**（domain warping + 弱带 + 分层地形）——打破 Voronoi、网格和直线边界感。
4. **水文 D8**（§4.4，已验证桶排序）——河流顺高程入海，湖泊由盆地和水量解释。
5. **气候双路降水**（§B）——保证沙漠/雨林在物理位置。
6. **合理性检查与局部修复**（§4.9）——发现并修复规则海岸、无来源湖泊、旧边界残影等异常。
7. **生物群落查表**——把气候转成可读地貌。
8. **参数导航 + 收敛出图**（§C.1）——作者调参，物理出图。
9. **3D 展示与导出**（§C.3）——增量。

每一步都以「输出地貌是否满足 §A 因果链」为验收标准。

## E. 新生成管线适配（pipelineMode / geology-v2）

当前实现进入过渡期：保留可运行的 legacy 构造逻辑，同时引入 `pipelineMode`、状态层、派生层和 geology-v2 模块边界，方便后续逐步替换板块、地壳、水文、气候生成管线。

### E.0 推荐生成顺序

geology-v2 的长期方向应采用“板块构造提供骨架 + 地壳属性派生海拔 + 海平面后置切分 + 水文/气候校验”的顺序：

1. 生成板块：板块中心、速度、年龄、弱带和不规则边界。
2. 给板块与网格赋地壳属性：`crustType`、`crustThickness`、`crustAge`、`crustDensity`、`weakness`。
3. 计算板块边界类型：汇聚、张裂、转换、稳定内部。
4. 生成基础海拔场：由地壳浮力、洋壳年龄、地壳厚度和旧构造记忆派生。
5. 添加构造特征：山脉、海沟、裂谷、岛弧、洋中脊、沉积盆地。
6. 加入多尺度扰动：domain warping、弱带偏移、大陆边缘扰动、局部地质事件。
7. 求解海平面：根据水量切出当前大陆、浅海、大洋、内陆湖候选。
8. 水文：河流、湖泊、流域和沉积搬运。
9. 简化侵蚀：削低旧山带、填平异常深坑、拓宽沉积盆地。
10. 气候：温度、降水、雨影、寒流/暖流和海陆热力差异。
11. 生物群系/地貌分类：由气候、水文和海拔派生。
12. 合理性检查与局部修复：规则海岸、异常湖泊、棋盘山脉、海底旧边界残影等进入诊断和修复流程。

该顺序的关键约束是：**任何阶段都不直接把随机值写成最终地貌；随机性只扰动物理场，最终地貌必须由状态层和派生层共同推出。**

### E.1 为什么引入 pipelineMode

旧版 `tectonicsStep → erosion → seaLevel` 已经能运行并提供可视结果，但它把板块漂移、地壳状态、构造特征和最终高程耦合得较紧。直接重写会破坏当前可用版本，也很难逐步验证。

因此新增：

- `pipelineMode: "legacy"`：默认模式，继续走现有稳定路径。
- `pipelineMode: "geology-v2"`：新管线骨架，当前先复用 legacy 的核心计算，但把阶段边界拆出来。

这让后续可以逐段迁移：先替换地壳状态，再替换边界求解，再替换水文和气候，而不需要一次性重写全部地形算法。

### E.2 state 与 derived 边界

长期状态层（state）记录“世界真的拥有的历史和物性”，可以跨时间累积：

- `plate / plateId`
- `crustType`
- `crustThickness`
- `crustAge`
- `crustDensity`
- `weakness`
- `orogeny`
- `sediment`

派生层（derived）记录“从状态重建出来的当前表现”，应可重算：

- `baseElevation`
- `tectonicElevation`
- `finalElevation / elev`
- `seaMask`
- `boundaryType / btype`
- `boundaryInfluence`

兼容期内，旧字段仍保留：

- `crust` 继续作为旧大陆度/地壳连续场。
- `relief` 继续作为旧长期构造起伏。
- `boundaryRelief` 继续作为旧当前活动边界起伏。

但 geology-v2 后续应优先写入 state，再通过统一海拔重建入口生成 derived。

### E.3 legacy 与 geology-v2 职责

legacy：

- 入口：`runLegacyStep(world)`
- 目标：保持现有页面和验证结果基本稳定。
- 允许继续使用旧字段和旧构造逻辑。

geology-v2：

- 入口：`runGeologyV2Step(world)`
- 阶段顺序：
  1. `advectCrust(world)`
  2. `updatePlateBoundaries(world)`
  3. `updateCrustProperties(world)`
  4. `buildTectonicFeatures(world)`
  5. `rebuildGeologyElevation(world)`
- 当前是骨架和兼容层：部分阶段仍薄封装 legacy 结果。
- 后续每个阶段都应只负责自己的 state 或 derived，不直接把板块边界永久写入最终海拔。

### E.4 海拔重建规则

不再推荐在板块边界逻辑中直接永久写 `elev`。推荐规则：

- 长期状态写入：`crustThickness`、`crustAge`、`crustType`、`orogeny`、`sediment`、`weakness`。
- 活动边界只生成当前边界特征或写入可衰减的构造状态。
- 最终海拔由 `rebuildElevation(world)` 或 `rebuildGeologyElevation(world)` 统一派生。

legacy 兼容期内可以继续使用 `elev`，但新增 geology-v2 阶段必须遵守这个方向。

### E.5 后续迁移顺序

1. 将 `crust` 的含义拆分为 `crustType + crustThickness + crustDensity`。
2. 将 `relief` 的长期造山含义迁移到 `orogeny`。
3. 将活动海岭/海沟从 `boundaryRelief` 迁移到派生特征层。
4. 用 geology-v2 的 `updatePlateBoundaries` 替换 legacy 边界求解。
5. 引入水文和气候派生层，避免它们直接依赖临时边界像素。
6. 将渲染层逐步改为读取明确的 derived 字段。

### E.6 分辨率尺度

新增统一尺度 helper：

- `REFERENCE_WIDTH = 512`
- `REFERENCE_HEIGHT = 256`
- `resolutionScale(grid)`
- `cellsFromReference(worldOrGrid, value)`

边界宽度、扩散半径、漂移速度、平滑半径等后续都应通过该 helper 表达为“参考分辨率下的物理尺度”，减少同种子不同分辨率产生完全不同世界的问题。

### E.7 geology-v2 拆分进展

当前阶段已从 legacy `tectonics.js` 中拆出 geology-v2 的第一批真实逻辑：

- `geology/plates.js`
  - `advectPlatesV2(world)`：按板块速度移动板块中心。
  - `rasterizePlatesV2(world)`：按弱带和地壳厚度代价重新栅格化 `plate`。
  - `advectCrustByPlateMotion(world)`：半拉格朗日平流 `crustType`、`crustThickness`、`crustAge`、`orogeny`、`sediment`。
- `geology/boundaries.js`
  - `updatePlateBoundariesV2(world)`：生成带状 `boundaryInfluence`。
  - `classifyBoundaryKindV2(world)`：按相邻板块相对速度分类 `convergent / divergent / transform / interior`。
- `geology/crust.js`
  - `updateCrustPropertiesV2(world)`：维护洋壳年龄、壳厚、密度、裂谷减薄、走滑弱化、汇聚增厚/俯冲条件。
- `geology/features.js`
  - `buildTectonicFeaturesV2(world)`：生成派生构造特征 `mountainBelt / trench / ridge / rift / islandArc / basin`，并写入 `tectonicFeature / featureIntensity`。
- `geology/elevation.js`
  - `rebuildGeologyElevationV2(world)`：由壳厚、洋壳年龄、`orogeny`、构造特征和噪声统一派生 `elev`。

geology-v2 已移除“完整 `tectonicStep` 桥接调用”。legacy 模式仍保留旧 `tectonics.js` 路径，用于兼容当前可运行版本。

### E.8 新状态与派生字段

新增或明确复用的状态字段：

- `crustType`：0=洋壳，1=陆壳。
- `crustThickness`：归一化地壳厚度，控制大陆浮力和洋壳深度。
- `crustAge`：归一化地壳年龄，洋壳越老越冷却下沉。
- `crustDensity`：派生/近似密度，用于后续俯冲和等静力模型。
- `orogeny`：长期造山根，属于可累积 state。
- `sediment`：沉积物/盆地填充潜力，属于 state。
- `weakness`：岩石圈弱带，影响板块边界弯曲与构造集中。

新增派生字段：

- `boundaryKind`：geology-v2 的边界类型；当前同步兼容 `btype`。
- `boundaryInfluence`：带状边界影响，不是单像素线。
- `tectonicFeature`：当前主导构造特征枚举。
- `featureIntensity`：当前主导构造特征强度。
- `mountainBelt`、`trench`、`ridge`、`rift`、`islandArc`、`basin`：当前活动构造特征层，随时间衰减。

### E.9 仍保留的 legacy 依赖

geology-v2 当前仍复用：

- `assignPlates(world)`：初始板块种子和速度仍由 legacy 初始化。
- `BoundaryType` 枚举：避免重复定义边界类型常量。
- `updateSeaLevel(world)` / `initializeSeaLevel(world)`：水体体积和海平面求解继续用现有稳定实现。
- `terrain.js` 的初始噪声/初始地形字段：v2 仍从当前基础地形状态启动。
- 渲染层仍读取 `elev / btype / activeBoundary` 等兼容字段。

这些依赖是有意保留的兼容层，不再包含完整 `tectonicStep` 求解。

### E.10 下一阶段建议

水文/气候接入前，地质层还需要补强：

1. 建立更明确的板块边界几何缓存，减少派生特征中的残余直线感。
2. 将 `assignPlates` 初始生成拆入 geology-v2，避免初始状态仍由 legacy 控制。
3. 将 `crust` 旧大陆度彻底降级为兼容 derived，不再作为任何 v2 state 的来源。
4. 为 `trench / ridge / rift / basin` 建立邻域扩散，避免过窄活动线。
5. 在水文接入前稳定 `basin` 和 `sediment`，让湖泊/河流读取盆地状态而不是临时高程噪声。
6. 在气候接入前稳定山带宽度与高度，保证雨影和迎风坡有足够地形尺度。

### E.11 分辨率归一化进展

当前实现不再把“同种子 + 同参数 + 不同分辨率”视为完全相同的逐像素结果，而是约束为同一世界在不同网格上的近似采样：

- 初始大陆度、弱带和 geology-v2 海拔噪声统一改为格心球面坐标采样，避免分辨率改变时采样相位整体偏移。
- 板块初始中心新增归一化 `centersU / centersV`，再派生当前网格坐标 `centersX / centersY`，减少不同分辨率下板块落点不一致。
- 平均板块漂移统计改为参考 512×256 格数，避免 256 和 1024 的漂移量看起来不可比。
- `tools/resolution-check.mjs` 用统一世界坐标重采样不同分辨率结果，输出陆海比例、海岸复杂度、陆海分类差异、板块差异、海拔 RMSE 和特征覆盖统计。
- geology-v2 特征扩散改为本步最大影响场写回，降低边界像素数量随分辨率变化造成的累加强度差异。

仍需注意：这不是严格解析无关模拟。长期演化中，海平面反馈、边界栅格化、半拉格朗日平流和低分辨率的信息损失仍会让 256×128 与 512×256 出现可见差异。验收时应比较大体大陆格局、海陆比例、板块漂移和海岸复杂度，而不是要求大陆轮廓、山脉和海岸线完全重合。

### E.12 地壳记忆生命周期

geology-v2 新增长期地壳循环规则，用于区分“当前构造特征”和“长期地壳记忆”：

- `crustType` 现在支持 `0=oceanic`、`1=continental`、`2=transitional`。陆内离散边界会先减薄陆壳并生成过渡壳，只有在持续强张裂、低厚度和高弱化同时满足时才转为新洋壳。
- 洋中脊附近洋壳年龄会被重置为新生洋壳；远离海岭后 `crustAge` 逐步增长，海底深度主要由洋壳年龄控制。老洋壳在汇聚边界更容易被削薄、俯冲和沉积覆盖。
- `orogeny` 只作为大陆汇聚的长期记忆增长。非活动造山根会侵蚀、扩散并转化为沉积物，旧山带应逐步变成低缓高地，而不是长期保持新鲜边界线。
- `mountainBelt / trench / ridge / rift / islandArc` 仍是当前活动特征，快速衰减；`orogeny / sediment / crustAge / crustThickness` 才是长期记忆。
- `sediment` 和 `basin` 在低地、裂谷、被动陆缘和老洋壳区域累积，并通过低频扩散形成宽盆地，用来填平小型异常深坑和过度规则的旧边界低地。
- 被动海底和过渡壳的 `crustAge / crustThickness / sediment` 会低频平滑，减少半拉格朗日平流和类型硬切换造成的旧板块块状残影。

当前仍是近似模型：739 Myr 级别的长时程图中可能仍有少量海底色阶块和长山带，但旧构造残影已明显少于单纯边界描线阶段。

### E.13 海陆后置验证层与地质诊断

当前 geology-v2 已把最终海陆关系放在派生层处理：`terrain.js` 生成的初始 `crust` 只作为 initial crust affinity，用来初始化 `crustType / crustThickness / crustAge / weakness`；演化后 `crust` 与 `isContinental` 主要作为 legacy 渲染和统计兼容字段同步。最终陆地、海洋、海岸线仍以 `elev >= seaLevel` 判定，`elev` 由 `crustType / crustThickness / crustAge / orogeny / sediment / basin / active features` 统一重建，不能直接从初始海陆 mask 复制。

新增调试导出工具：

- `tools/geology-debug-render.mjs <seed> <steps> <outDir> <pipelineMode> <resolution>`。
- 默认导出 PPM：`crustType`、`crustThickness`、`crustAge`、`orogeny`、`sediment`、`basin`、`finalElevation`、`seaMask`、`boundaryInfluence`、`boundaryKind`。
- 调试目标是把异常归因到地壳类型、壳厚、洋壳年龄、沉积/盆地、海平面切分或边界派生层，而不是只看最终配色。

`tools/long-run-check.mjs` 和 `tools/resolution-check.mjs` 新增 geology diagnostics：

- `coastBoundaryShare`：海岸格中靠近活动边界、精确落在边界线上的比例，用来发现海岸被板块边界硬切。
- `featureStats.*.boundaryZeroShare`：山带、海沟、海岭、裂谷、岛弧、盆地落在单像素边界上的比例，用来发现过窄特征。
- `oldBoundarySeafloorSignal`：海底非活动边界和旧特征的相关信号，用来发现旧边界残影。
- `inlandBasinRisk`：低于海平面的独立小水体候选及其盆地/沉积解释比例；水文接入前只作为风险指标。
- `crustStats.fields`：`crustThickness / crustAge / orogeny / sediment / basin` 的均值、极值和覆盖率。
- `resolution-check` 在 256/512/1024 之间输出 `landMismatchVsBaseline`、`elevationRmseVsBaseline`、`coastlineRatio` 和同一套地质诊断，用于检查 200 Myr 级别的分辨率收敛。

本轮验证样例（`龙骨海-纪元7`，geology-v2，512×256，1 Myr/步）显示：200 Myr 陆地约 51.8%，海岸近边界比例约 14.8%，精确边界约 5.4%；739 Myr 陆地约 48.5%，未出现极端陆海漂移。`seaMask` 与 `crustType` 调试图明显不一致，说明过渡壳和洋壳区域会经由高程与海平面切分成不同海陆结果，而不是按类型或初始 mask 直接裁剪。

剩余地质风险：

- `crustAge` 在长时程半拉格朗日平流后仍可能出现较直的宽域色带；最终高程中已被沉积/盆地和海平面弱化，但后续应改为更物理的海岭新生洋壳年龄传播模型。
- `longStraightFeatureSignal` 仍偏高，因为当前指标会把连续山带和海岭也算作直线信号；后续应区分自然山带轴线、活动边界和非活动残影。
- `inlandBasinRisk` 目前只能发现低于海平面的水体候选，不能判断河流补给、蒸发和溢流；进入水文阶段后需要由湖泊/流域求解替代。
- `assignPlates` 与初始地形仍来自 legacy 启动路径；中长期应将初始板块、弱带和地壳亲和度完全拆入 geology-v2 初始化模块。

### E.14 后续系统派生接口层

当前新增 `src/sim/derived/terrain.js` 作为 geology-v2 到后续系统之间的最小接口骨架。它提供：

- `getTerrainDerived(world)`
- `getClimateInputs(world)`
- `getHydrologyInputs(world)`
- `getBiosphereInputs(world)`
- `getResourceInputs(world)`

这些 getter 只读当前 `world`，不推进模拟时间，不写回 geology-v2 state，也不实现真正的气候、水文、生物圈或资源分布。它们的职责是把 `elev / seaLevel / crustType / crustThickness / crustAge / orogeny / sediment / basin / tectonic features` 组织成稳定的 TypedArray 输入，供后续模块读取。

接口层已暴露的基础派生字段包括：

- 地形：`relativeElevation`、`landMask`、`seaMask`、`shallowSeaMask`、`deepOceanMask`、`slope`、`aspect`、`ruggedness`、`coastDistance`、`distanceToOcean`、`landmassId`、`islandId`。
- 气候输入：`latitude`、`oceanDepth`、`orographicBarrier`、`mountainAxis`、`mountainHeight`。
- 水文输入：`hydroElevation`、`externalSeaMask`、`oceanConnectivity`、`closedBasinId`、`depressionMask`、`erodibility`、`permeability`、`sedimentSink`。
- 生物圈输入：`soilParentMaterial`、`soilDepthPotential`、`groundwaterPotential`、`floodplainPotential`、`coastalWetlandPotential`、`volcanicSoilPotential`、`disturbance`、`connectivityToLandmass`。
- 资源输入：`volcanicArc`、`riftStage`、`passiveMargin`、`sedimentaryBasin`、`metamorphicBelt`、`igneousProvince`、`hydrothermalPotential`、`mineralProvince`。

仍需明确的占位字段：

- `waterAvailability` 目前为 0，等待气候/水文层回填。
- `mineralProvince` 目前为 0 编号，等待资源分区。
- `riftStage / passiveMargin / hydrothermalPotential` 是现有地质字段的近似解释，不代表完整模型。
- `closedBasinId` 只是低于海平面且不属于最大外海连通域的候选水体，不是最终湖泊系统。

新增 `tools/interface-check.mjs` 用于检查接口契约。它会创建指定 seed、步数、模式和分辨率的 world，调用全部 getter，验证字段存在、TypedArray 类型和长度等于 `grid.size`，并输出陆海比例、浅海/深海比例、陆块/岛屿数量、外海/内陆水体候选、封闭盆地数量、平均坡度、粗糙度、地形屏障覆盖率和沉积汇覆盖率。

验证命令：

```powershell
node .\tools\interface-check.mjs '龙骨海-纪元7' 0 geology-v2 512x256
node .\tools\interface-check.mjs '龙骨海-纪元7' 20 geology-v2 512x256
```

后续气候、水文、生物圈和资源模块应读取这些 getter 输出，而不是直接散读 geology-v2 内部临时字段。若后续系统需要反作用地貌，应通过明确的反馈通道进入地质层，例如侵蚀、沉积或湖泊填充，而不是任意改写 `elev`。

### E.15 洋壳年龄出生场与洋底高程分项

当前 geology-v2 已将洋壳年龄从“主要由半拉格朗日平流搬运的贴图”改为“由活动洋中脊出生并按扩张距离/时间增长的年龄场”：

- 活动海岭格（`ridge` 或活动离散边界上的洋壳）每步将 `crustAge` 重置到年轻值，近似表示新洋壳出生。
- 洋壳离开海岭后按 `1 / 200` 每 1 Myr 增长，归一化 `crustAge = 1` 约等于 200 Ma，避免无限变老和无限下沉。
- 洋壳年龄会受 `ridgeDistance` 距海岭距离约束；距离场低频重建，海岭格仍每步归零。这样减少长时程贴图平流残影，同时避免高分辨率验证被每步全图 BFS 拖垮。
- 过渡壳和大陆壳继续使用独立慢年龄规则，不套用洋壳出生/扩张年龄场。
- `advectCrustByPlateMotion` 不再平流洋壳 `crustAge` 作为主来源，但仍平流壳厚、造山和沉积等长期状态。

洋底高程也拆为可解释项，并写入 grid 供诊断和 debug render 使用：

- `ageSubsidence`：洋壳随年龄冷却、增密、热沉降，使用有上限的非线性年龄项。
- `thicknessBuoyancy`：壳厚带来的浮力/厚度项。
- `sedimentFill`：沉积物填平海底与陆缘盆地，使沉积区更浅、更平。
- `ridgeUplift`：活动洋中脊附近的浅海岭抬升。
- `trenchDepression`：俯冲海沟附近的局部下陷。
- `oceanDepthTerms`：上述洋底项的合成调试场。

新增诊断：

- `depthAgeCorrelation`
- `ridgeAgeResetShare`
- `youngOceanDepthMean`
- `oldOceanDepthMean`
- `ageBandStraightness`
- `oceanDepthTerms.*Mean`

新增 debug 图层：

- `oceanAge`
- `ageSubsidence`
- `sedimentFill`
- `oceanDepthTerms`

验证样例（`龙骨海-纪元7`，geology-v2，512×256，1 Myr/步）：

- 200 Myr：`depthAgeCorrelation ≈ 0.90`，`ridgeAgeResetShare = 1`，年轻洋壳平均水深约 `0.134`，老洋壳约 `0.195`。
- 739 Myr：`depthAgeCorrelation ≈ 0.85`，`ridgeAgeResetShare = 1`，年轻洋壳平均水深约 `0.133`，老洋壳约 `0.189`。
- 200 Myr 分辨率检查已覆盖 256×128、512×256、1024×512；相对 512 基线，256 与 1024 的陆海 mismatch 均约 `3.4%`，仍保持可接受收敛。

剩余风险：`ageBandStraightness` 仍偏高，因为年龄带天然会沿海岭近平行展开，当前指标还不能完全区分“合理的洋壳年龄条带”和“被平流贴图拖出的直线残影”。后续应结合海岭距离、转换断层和 fracture zone 衰减进一步细化。

### E.16 裂谷阶段机与海洋连通性

当前 geology-v2 新增大陆裂谷阶段机，避免两个陆内板块反向移动时直接生成规则海或规则内陆湖。阶段枚举：

- `0 NONE`：无活动裂谷。
- `1 INCIPIENT_RIFT`：初始陆内张裂，弱带和离散边界开始减薄陆壳。
- `2 RIFT_BASIN`：裂谷盆地，`basin / sediment` 增长，地形可降低，但仍不直接解释为外海。
- `3 TRANSITIONAL_RIFT`：持续张裂且壳厚降低后转为过渡壳。
- `4 PROTO_OCEAN_CANDIDATE`：年轻新生海盆候选，接近或低于海平面，但尚未连通外海时仍是候选盆地。
- `5 CONNECTED_YOUNG_OCEAN`：低于海平面、连通外海且持续张裂后，才转为年轻洋盆。

阶段推进逻辑使用：

```js
riftPower = max(
  divergentBoundary * boundaryInfluence * stress * weakness,
  riftFeature * weakness
)
```

核心约束：

- `TRANSITIONAL_RIFT -> OCEANIC` 的旧快捷转换已收紧，只有 `CONNECTED_YOUNG_OCEAN` 才允许稳定转为年轻洋壳。
- 低于海平面但不连通外海的裂谷盆地会标记为 `inlandWaterCandidate / closedBasinId`，不会在地质解释层直接视为外海。
- 旧裂谷若停止张裂会缓慢衰退，保留为低地、沉积盆地和弱带，而不是永久直线海。

海洋连通性字段：

- `externalSeaMask`：最大连通海域，x 方向 wrap，y 方向不 wrap。
- `oceanConnectivity`：`0=陆地/非水体`，`1=内陆候选水体`，`2=外海`。
- `inlandWaterCandidate`：低于海平面但不属于外海。
- `closedBasinId`：内陆候选水体连通域编号。

- `transitionalToOceanicRate`

- `unconnectedBelowSeaRiftShare`

- `riftCoastBoundaryShare`

新增 debug 图层：

- `riftStage`
- `externalSeaMask`

剩余风险：当前外海定义采用最大连通海域，适合当前球面展开拓扑和诊断用途，但还不是完整海峡/潮汐/湖泊水文模型。后续水文接入后，应由湖泊填充、溢流口、蒸发和河流补给进一步决定内陆水体是否真实存在。

### E.17 被动大陆边缘、大陆架与深海平原

当前 geology-v2 新增被动大陆边缘派生层，用来解释“陆地到深海”的连续过渡，而不是让海岸线或浅海边界硬贴板块边界。新增字段：

- `passiveMargin`：非活动陆缘、过渡壳和陆洋过渡带的综合强度。
- `continentalShelf`：靠近外海、近岸、浅水且沉积物较多的大陆架。
- `continentalSlope`：大陆架外侧较陡的陆坡过渡带。
- `continentalRise`：陆坡外侧由沉积楔塑造的缓坡陆隆。
- `abyssalPlain`：老洋壳、低构造活动、高沉积的平缓深海平原。
- `sedimentWedge`：被动陆缘沉积楔，对浅海和陆隆有填浅、平滑作用。

派生原则：

- 必须靠近 `externalSeaMask`，不把 `closedBasin / inlandWaterCandidate` 误解释为被动大陆边缘。
- 必须远离活动边界，`boundaryInfluence / ridge / trench` 强时抑制 `passiveMargin`。
- 优先出现在 `transitional crust`、陆壳-洋壳过渡带、沉积和盆地较强的区域。
- 高程影响保持温和：大陆架略抬浅、陆坡略压低、陆隆和沉积楔填浅，深海平原则降低局部粗糙度，不直接覆盖海陆后置结果。

- `passiveMargin`
- `continentalShelf`
- `continentalSlope`
- `continentalRise`
- `abyssalPlain`
- `sedimentWedge`

剩余风险：当前被动陆缘仍是地质状态派生层，不是完整海岸动力、波浪、三角洲或碳酸盐台地模型。后续进入水文/气候后，河流输沙、海流、气候带和生物礁会继续改变浅海与海岸细节。

### E.18 转换断层寿命与旧 fracture zone 衰减

当前 geology-v2 新增转换断层记忆层，用来区分当前活动的 transform boundary 和已经停止活动的 oceanic fracture zone。核心目标是：活动转换断层可以有局部线性地貌和弱带增强，但旧 fracture zone 只能保留弱带、少量年龄差和低幅纹理，不能长期成为强高程线或规则深浅带。

新增字段：

- `activeTransform`：当前活动转换边界强度，来自 `boundaryKind === TRANSFORM`、`boundaryInfluence` 和 `stress`。
- `transformMemory`：转换断层弱带记忆，主要服务后续板块边界偏好和资源/构造诊断。
- `fractureZoneMemory`：洋壳旧转换断层或海岭错断带记忆，允许保留低幅年龄/纹理差异。
- `inactiveBoundaryRelief`：旧边界残留在高程中的风险强度，用于诊断和抑制。
- `oldBoundaryCorrelation`：海底高程变化与旧边界记忆的相关度诊断。
- `ageBandStraightnessRisk`：远离 active ridge 的年龄条带直线风险。

实现原则：

- active transform 会写入 `activeTransform`，轻微增强 `weakness / transformMemory`，并在高程层产生很小的局部 relief。
- oceanic inactive transform 的高程贡献快速衰减；fracture-zone memory 可以衰减得慢一些，但主要作为纹理/弱带，而不是高程线。
- continental transform 可保留更长时间的 `weakness`，但不保留强线性高程。
- `suppressInactiveFractureRelief` 只在远离 active ridge/trench/boundary 的洋壳上做小半径条件平滑，不全局模糊海岭、海沟、岛弧或新山带。
- 远离 active ridge/trench/boundary 的旧 fracture zone 会低频软化 `crustAge / crustThickness / sediment` 源场，减少由年龄条带继续派生出的规则深浅色带。

新增诊断：

- `activeTransformCoverage`
- `transformMemoryCoverage`
- `fractureZoneMemoryCoverage`
- `inactiveTransformReliefMean`
- `fractureZoneElevationContribution`
- `oceanicStraightReliefDecay`
- `oldBoundaryReliefCorrelation`
- `activeVsInactiveBoundaryReliefRatio`
- `ageBandStraightnessNearRidge`
- `ageBandStraightnessInactive`
- `ageBandStraightnessFractureZone`
- `abyssalPlainFractureSuppression`

新增 debug 图层：

- `activeTransform`
- `transformMemory`
- `fractureZoneMemory`
- `inactiveBoundaryRelief`
- `oldBoundaryCorrelation`
- `ageBandStraightnessRisk`

剩余风险：`ageBandStraightness` 总指标仍可能很高，因为真实洋壳年龄条带会沿海岭平行展开。后续应重点观察拆分后的 `ageBandStraightnessInactive / ageBandStraightnessFractureZone`，而不是只看总值。

### E.19 板块挤压区棋盘格边界伪影修复

本轮修复 geology-v2 在板块挤压区偶发的红蓝交替棋盘格边界伪影。根因在于 plate rasterization 的 8 邻域扩张曾让对角移动成本低于正交移动，容易在局部竞争区形成 A/B/A/B 的 plate 归属；随后 `activeBoundary` 被面状化，构造 feature 又会放大这类数值噪声。

修复策略：

- `rasterizePlatesV2` 的对角邻域成本改为 `Math.SQRT2`，不再鼓励对角捷径。
- rasterization 后增加轻量 majority cleanup：只清理 8 邻域中明显孤立的 plate cell 和典型 2x2 棋盘格，不全局抹平真实长边界。
- `updatePlateBoundariesV2` 派生 `boundaryDensity / boundaryCoherence / noisyBoundaryPatch / plateCheckerboard`。
- 面状噪声 patch 会降低 `boundaryInfluence` 和 boundary stress，防止数值噪声进入 `mountainBelt / trench / ridge / rift / basin`。
- coherent active boundary 仍保留造山、海岭、海沟和转换断层信号。

新增诊断：

- `plateCheckerboardScore`
- `activeBoundaryCoverage`
- `localBoundaryDensityMean`
- `noisyBoundaryPatchCoverage`
- `plateIslandNoiseShare`
- `featureOnNoisyBoundaryShare`

新增 debug 图层：

- `plateId`
- `boundaryDensity`
- `boundaryCoherence`
- `noisyBoundaryPatch`
- `plateCheckerboard`

剩余风险：当前 cleanup 是局部栅格规则，不是真正的连续几何板块边界重建。若后续仍看到长段边界过直，应进入“边界分段弯曲与轴线生成”任务，而不是继续提高 majority cleanup 强度。

### E.20 造山带生命周期重构

本轮 geology-v2 将活动山带和长期造山根分离。`mountainBelt / activeOrogeny` 表示当前活动汇聚边界附近的新山带，应清晰、较高、与 convergent boundary 有因果关系；`orogeny / oldOrogeny` 表示长期造山根和旧山带，应随时间侵蚀、扩宽、降低、断续化，而不是长期保留单像素板块边界线。

新增字段：

- `activeOrogeny`：当前活动汇聚、陆陆碰撞或俯冲弧造山强度。
- `oldOrogeny`：非活动旧造山根，主要存在于 continental / transitional crust，低缓、宽、断续。
- `orogenyAge`：造山记忆年龄，用于降低旧山带高程贡献。
- `orogenyErosion`：本步由新旧山带侵蚀释放的物质量。
- `orogenicSedimentSupply`：可供沉积系统读取的造山物源。
- `forelandBasin`：造山带前缘的宽缓沉降/沉积盆地候选。
- `mountainAxis / mountainHeight / orographicBarrier`：给后续气候、水文读取的山脉轴线、高度和雨影屏障。

实现原则：

- active convergence 只在 coherent boundary 上强写入；`noisyBoundaryPatch` 会显著降低造山信号，避免棋盘格边界进入山脉系统。
- `mountainBelt` 半衰期较短，用来表现新山带；`orogeny / oldOrogeny` 半衰期更长，但高程贡献会随 `orogenyAge` 降低。
- 旧造山带通过小半径、低频、受 `weakness` 偏转的扩散变宽，并用 segment mask 做断续化。
- 侵蚀量写入 `orogenyErosion / orogenicSedimentSupply`，并按 `forelandBasin / basin / passiveMargin / continentalRise` 等 sink 局部增加沉积。
- `forelandBasin` 只在山带附近、低缓的 continental / transitional crust 上增强，表现为宽缓低地和沉积汇，不是深坑或随机贴图。
- 管线每步只推进一次 `updateOrogenicLifecycle`；最终 `updateSeaLevel` 后重新刷新 `mountainAxis / mountainHeight / orographicBarrier`，保证接口层读取的是最终高程状态。

- `orogenicSedimentBudget`

剩余风险：当前 mountain axis 仍是栅格场派生，不是连续山脉骨架追踪；沉积搬运也还是局部 sink 规则，不是完整河流/气候输沙。后续进入水文和气候后，应让降水、河网、坡面侵蚀继续修正 `orogenicSedimentSupply` 的去向。

### E.21 构造轴线自然化

本轮 geology-v2 新增 naturalized tectonic axis 层，目标是让山脉、海岭、海沟和裂谷不再逐像素复制 `activeBoundary / boundaryInfluence`。raw boundary 只作为 coherent seed；最终 feature 写入读取经过弱带、旧造山根、裂谷阶段、transform/fracture memory 偏转和扩宽后的轴线场。

新增字段：

- `tectonicAxis`：综合构造轴线。
- `mountainAxisSeed`：自然化山脉/造山轴线。
- `ridgeAxis`：自然化洋中脊轴线。
- `trenchAxis`：自然化海沟/俯冲轴线。
- `riftAxis`：自然化裂谷轴线。
- `axisSegmentId`：轴线连通段编号，用于诊断 segment length。
- `axisCurvature`：局部轴线弯曲/方向变化强度。
- `axisContinuity`：局部轴线连续性。
- `axisBoundaryDependency`：轴线对 raw active boundary 的依赖度。
- `mountainHeightBlockiness`：山高字段块状/条纹风险。
- `orographicBarrierContinuity`：雨影屏障连续性。

实现原则：

- `boundaryInfluence * boundaryCoherence * stress` 只生成候选 seed；`noisyBoundaryPatch / plateCheckerboard` 会强烈抑制 seed。
- `axes.js` 用小半径局部扩散和二维低频 segment mask 生成自然化轴线，避免 `id` hash 导致固定竖纹/横纹。
- `buildTectonicFeatures` 以 `mountainAxisSeed / ridgeAxis / trenchAxis / riftAxis` 为主源，raw seed 只保留弱因果补充。
- `rebuildMountainInterfaceFields` 优先读取自然化山脉轴线，并对 `orographicBarrier` 做局部平滑，使气候接口更连续。
- transform 仍主要提供弱带和偏转记忆，不直接生成强山脉轴线。

### E.22 行星地形起伏预算

本轮 geology-v2 新增 `planetary relief budget` 诊断层，用于防止长时程后侵蚀、沉积、被动边缘平滑和深海平原机制叠加，把世界拉成缺少高差的“平板世界”。该层只读最终 `elev / seaLevel` 和已有地质状态，初版不直接修改 `elev`，也不通过随机噪声制造起伏；海陆仍由 `elev >= seaLevel` 后置派生。

新增字段：

- `planetaryRelief`：构造/等静力来源扣除削平压力后的局部起伏预算。
- `tectonicReliefSupply`：`activeOrogeny / oldOrogeny / ridge / rift / trench / islandArc` 合成的构造起伏来源。
- `isostaticReliefSupply`：`ageSubsidence / thicknessBuoyancy / oceanDepthTerms` 的等静力和洋底起伏来源。
- `erosionFlatteningPressure`：沉积、盆地、深海平原、沉积楔和前陆盆地造成的削平压力。
- `sedimentSmoothingPressure`：沉积楔、深海平原、前陆盆地等平滑项子集。
- `reliefDeficit`：相对于目标 hypsometric spread、land relief spread 和 global std 的起伏不足风险。
- `seaLevelSensitivity`：接近海平面的区域，表示海陆后置对海平面变化的敏感度。
- `flatLandMask / largePlainMask`：局部平原和大平原候选；平原允许存在，只有与低全局 spread/std 同时出现才是风险。

新增全局诊断：

- `globalElevationStd / landElevationStd / oceanElevationStd`
- `hypsometricSpread / landReliefSpread / oceanReliefSpread`
- `flatLandShare / largePlainShare`
- `seaLevelSensitivity / coastInstabilityRisk`
- `tectonicReliefSupplyMean / isostaticReliefSupplyMean`
- `erosionFlatteningPressureMean / sedimentSmoothingPressureMean`
- `drainageGradientPotential / orographicReliefPotential`

约束：

- 起伏预算是诊断和质量约束，不是独立造山器。
- 局部大平原、陆架、深海平原和沉积盆地是允许的。
- 若后续启用反馈，应温和调节已有地质过程，例如旧造山记忆、构造保留和平滑强度，不应直接 `elev += randomNoise`。
- 撞击坑、热点、冰川、完整河网侵蚀和生物礁仍暂缓到独立阶段。
