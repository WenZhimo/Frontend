# 磷光矩阵视觉规范

本文档由参考图逆向推导而来。参考图优先级高于任何文字描述；当出现歧义时，以图像中呈现的物理显示效果为准。

本文档只定义视觉身份与验收标准，不定义实现方式，不选择技术路线，也不提供工程方案。

## 1. 执行摘要

该视觉系统的核心身份是：被摄影机近距离拍摄的冷蓝白磷光矩阵显示。

它不是普通复古屏幕效果，也不是通用的发光文字风格。它应被理解为一个真实的物理发光介质：无数独立微型发光单元组成文字、波形和亮斑。每个发光单元都有自己的高亮核心、蓝紫外晕和可见暗缝。即使在最亮区域，矩阵结构仍必须成立。

画面的整体气质应是安静、冷冽、克制、科学仪器式的，而不是娱乐化、霓虹化或故障化。

## 2. 显示身份

该显示最接近以下视觉类型：

- 高密度单色发光矩阵
- 冷蓝白磷光仪表显示
- 科学仪器信号屏
- 实验室观测显示
- 被摄影机捕捉的物理自发光阵列

它不应被归类为普通 OLED、LCD、CRT 电视、传统绿色终端、VHS 画面或赛博朋克霓虹屏。

参考图中的光不是由一个连续表面均匀发出，而是由大量独立、规则排列的微型发光单元共同构成。文字和波形都不是平滑图形，而是被矩阵采样后的发光结果。

## 3. 视觉特征

### 显示介质

显示介质应呈现为单色冷蓝白自发光阵列。光源来自显示平面中的离散单元，而非覆盖在图形外侧的统一光效。

显示表面应显得真实、厚重、被镜头捕获过。画面不是完全干净的数字合成，而应具有低光摄影中的轻微柔化、暗部雾感和有限动态范围。

### 像素结构

像素或发光单元必须可见。其结构应具有以下特征：

- 高密度正交矩阵
- 单元之间有稳定暗缝
- 单元近似方形或短矩形
- 明暗边界由离散单元组成
- 亮区内部仍可辨认矩阵
- 暗区中矩阵可隐约存在，但不应过度抢眼

矩阵不是装饰纹理，而是该视觉系统的骨架。

### 网格几何

网格应规则、均匀、细密。横向与纵向间距应稳定，不能出现随意颗粒化或噪点化。

网格在亮区内必须穿透高光。在强发光区域，外晕可以融合，但内部仍应能读出单元排列。

### 单元形态

每个发光单元应具有独立发光感：

- 中央亮度最高
- 边缘柔和衰减
- 相邻单元之间有轻微串光
- 串光不能完全抹平暗缝
- 强亮单元可接近白色
- 弱亮单元偏蓝、偏虚、偏暗

单元不应呈现为锐利纯色小方块，也不应融合成没有结构的连续光带。

### 像素密度

像素密度应高于传统低分辨率点阵屏，但仍足以被肉眼识别。参考图中的矩阵不是粗大的 LED 招牌颗粒，而是细密、微型、近距离拍摄下才明显的发光阵列。

### 亮度分布

亮度层级应呈现为：

1. 白热核心
2. 冷蓝高亮
3. 蓝紫扩散
4. 深蓝黑暗场
5. 近黑背景

最亮点可以接近白色，但不能变成没有纹理的纯白块。高光应保留矩阵穿透感。

### Bloom 行为

Bloom 应来自发光单元本身，而不是来自整个对象的统一外描边。

正确的 bloom 应表现为：

- 单元级光晕彼此叠加
- 高亮密集区域形成更大外晕
- 外晕柔和、冷色、低频扩散
- 外晕不掩盖单元结构
- 中心亮度强，外围逐渐进入深蓝黑

错误的 bloom 是平滑、均匀、包裹整个字形或波形的数字 glow。

### 核心发光

核心发光应偏白、偏冷、局部饱和。文字主标题、波形尖峰和单点强光中央都应有白蓝核心。

核心区域应明亮但不扁平。即使接近饱和，也要保留发光单元之间的暗缝或采样痕迹。

### 外部发光

外部发光应偏蓝紫，范围较宽，边缘非常柔。它更像镜头扩散、空气散射和发光介质共同造成的观感，而不是清晰描边。

外部发光不应呈现彩虹色、红紫霓虹或多色渐变。

### 色彩

色彩应非常克制，几乎是单色系统。

主要色彩：

- 冷白蓝
- 冰蓝
- 电光蓝
- 淡蓝紫
- 深蓝黑
- 近黑

禁止将主视觉推向绿色终端、紫红赛博霓虹、彩色 RGB 分离或暖色霓虹。

### 对比与黑位

整体对比应很高。黑场应深、厚、低照度，但不是纯数字黑。暗部可以有极轻微的蓝灰雾感和摄影暗噪。

明亮内容应像从黑暗中发出，而不是贴在黑色背景上的图形。

### 动态范围

动态范围应表现为局部刺眼、整体克制。画面里允许小面积高亮接近饱和，但大面积画面仍应保持低亮度、低噪声和深暗氛围。

### 光扩散

光扩散应宽而柔，尤其在强亮点周围形成圆形或椭圆形辉光。扩散会降低整体锐度，但不能破坏矩阵识别。

### 镜头特征与失焦

画面应有轻微摄影式柔焦。边缘和小字可以更虚，强光边缘可以更散。失焦是光学观感，不应变成随机模糊或劣质压缩。

### 表面纹理

主要纹理来自矩阵结构。允许低照度摄影带来的细微噪声和暗部不均匀，但不应加入明显纸纹、划痕、玻璃裂痕、尘点或胶片颗粒作为主效果。

### 扫描线与栅格

参考图中最重要的是点阵矩阵，而不是横向扫描线。若出现栅格感，应以纵横矩阵为主。明显 CRT 扫描线会误导视觉身份。

### 噪声

噪声应极轻。它只用于支撑摄影感和暗部深度，不应成为画面主题。

禁止重噪声、雪花、信号损坏、撕裂、拖影或 VHS 风格干扰。

### 波形表现

波形不是连续矢量线，而是由矩阵单元采样出的发光信号。

波形应具有以下特征：

- 水平基线由密集发光点构成
- 尖峰处有白蓝核心
- 峰值边缘有垂直扩散和柔光
- 低振幅区域呈颗粒化、断续、密集闪烁感
- 远离高亮的波形可以逐渐衰减进暗场

波形不应像普通音频软件中的平滑线条。

### 字体表现

文字应呈现为点阵化、仪器化、全大写、宽字距。

主文字：

- 更亮
- 更接近冷白蓝
- 点阵结构清楚
- 有较强外晕

副文字：

- 更小
- 更暗
- 更蓝
- 更虚
- 字距仍较宽

文字不应呈现为现代平滑无衬线发光字，也不应像普通终端字体。

### 图形表现

所有图形元素都应服从矩阵采样。任何线、点、字、波形、符号都不能脱离发光单元阵列独立存在。

## 4. 主导设计原则

视觉优先级如下：

1. 独立发光单元
2. 可见矩阵结构
3. 冷蓝白磷光
4. 白热核心与蓝紫外晕
5. 摄影式柔焦与暗部扩散
6. 高黑位对比
7. 科学仪器式克制排版
8. 轻微低光摄影噪声
9. 无故障、无娱乐化装饰

其中前四项为不可牺牲特征。只要独立发光单元、矩阵结构、冷蓝白磷光或高光穿透矩阵被破坏，整体视觉即不再符合参考图。

## 5. 显示模型

该显示应被理解为：大量独立发光单元在黑色基底上发光。

每个单元都有自己的发光强度。对象的整体形状由这些单元的亮度分布形成。文字、波形和亮斑不是先存在一个完整图形再附加光效，而是由发光矩阵直接生成。

Bloom 的形成逻辑是：

1. 单个发光单元发出冷蓝白光
2. 相邻单元的光晕互相叠加
3. 高亮密集区域形成白蓝核心
4. 镜头和介质造成更宽的蓝紫扩散
5. 暗场吞没外缘，使边界柔和消失

因此，光晕应始终服务于矩阵，而不能覆盖矩阵。

## 6. 渲染特性

### 文字渲染

文字应具有点阵采样痕迹。笔画边缘应呈现由发光单元构成的台阶感和空隙感。

主标题可以更亮、更硬、更清楚；副标题应更暗、更虚、更像低强度发光。

### 波形渲染

波形应像仪器信号被发光矩阵显示出来。尖峰部分应具有强烈局部亮度，基线部分则应密集、颗粒化、低幅振荡。

强峰可以产生较宽光晕，但中心仍应显示矩阵结构。

### 亮斑渲染

单点强光应呈白色核心、冰蓝中圈、蓝紫外圈。中心可接近饱和，外圈应柔和衰减至深黑。

该亮斑是判断视觉是否正确的重要参考：高光越强，越要证明矩阵仍能穿透亮区。

### 空间与构图

画面应给黑场留下足够空间。发光内容不应填满画面。参考图中的视觉张力来自黑暗中的少量发光信息，而不是高密度界面堆叠。

构图应偏静态、中央、仪器化。允许少量纵向分组和水平波形，但整体不应变成复杂 UI 面板。

## 7. 色彩与光模型

### 色彩层级

| 层级 | 视觉描述 |
| --- | --- |
| 最高光 | 冷白、略带蓝，局部接近饱和 |
| 强光 | 冰蓝、电光蓝 |
| 中光 | 蓝紫、柔和扩散 |
| 弱光 | 深蓝灰、低亮度 |
| 暗场 | 深蓝黑、近黑 |

### 光感规则

- 光必须像从显示介质内部发出
- 强光区域要有白热核心
- 外晕必须冷色、柔和、宽散
- 暗场要吸收外缘，而不是形成清晰边框
- 发光强度由单元密度和单元亮度共同决定
- 色彩变化主要来自亮度变化，而不是多色设计

## 8. 视觉验收标准

以下标准用于判断后续视觉成果是否符合参考图。

### 必须满足

- 最亮区域内部仍能看到矩阵格点。
- 发光对象必须由独立单元构成。
- Bloom 不能遮蔽发光单元。
- 文字边缘必须呈现矩阵采样痕迹。
- 波形必须保留离散单元痕迹。
- 黑场必须深，并带有极轻微蓝灰暗部质感。
- 光应像真实显示器被拍摄，而不是平面数字合成。
- 主色必须保持冷蓝白体系。
- 外晕必须柔和，但不能让图形失去结构。
- 小字必须更暗、更虚、更仪器化。
- 高亮必须有白热核心和蓝紫外扩散。
- 画面应克制、安静、科学仪器化。

### 不得出现

- 高光变成没有矩阵结构的白色团块。
- 发光文字变成平滑矢量字。
- 波形变成连续曲线。
- 整个对象被统一描边式 glow 包裹。
- 暗部充满重噪声或故障纹理。
- 画面出现明显 CRT 电视曲率。
- 画面出现 RGB 分离或彩边错位。
- 色彩转向绿色终端、紫红霓虹或多彩赛博朋克。
- 网格只作为背景纹理，而不参与发光对象本身。
- 整体看起来像网页特效、海报滤镜或视频故障效果。

## 9. 负面参考

以下风格会破坏该视觉系统，不应使用。

### CRT 电视

参考图没有明显屏幕曲率、桶形畸变、彩色子像素错位或电视扫描线。使用 CRT 电视语言会把视觉导向错误年代和错误介质。

### 传统示波器

参考图中的波形不是连续电子束轨迹，而是矩阵采样显示。传统示波器的连续绿线、余辉拖尾和圆形屏幕语汇不适合。

### VHS 与模拟故障

参考图没有磁带雪花、画面撕裂、水平错位、色带漂移或录像损坏。故障风格会削弱科学仪器般的清洁与克制。

### 绿色终端

该视觉不是绿色命令行终端。其色彩核心是冷白蓝和蓝紫扩散，而不是荧光绿字符。

### 赛博朋克霓虹

参考图没有多色霓虹、红蓝对撞、强烈商业标识或高饱和夜景感。过度霓虹化会破坏低光、冷静、仪器化的气质。

### 平面数字 Glow

普通发光字通常是完整字形外加模糊光晕。参考图要求发光从矩阵单元内部生成，亮区内部必须保留结构。

## 11. 最终判断

如果一个画面在缩小观看时呈现为冷蓝白发光信息，在放大观看时能看见稳定矩阵结构，并且在最亮区域仍保留单元级发光痕迹，那么它接近参考图。

如果一个画面首先让人想到 CRT、VHS、赛博朋克、绿色终端、普通网页光效或平滑霓虹字，那么它偏离了参考图。

该视觉系统的本质不是“复古”，而是“被拍摄到的冷蓝白物理发光矩阵”。
