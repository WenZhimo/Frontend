[ 新手说明 ]

这里是统一的模型管理入口：先在候选模型里选中一个模型，再决定是设为默认、重新评估，还是查看它对应的 checkpoint / resume 信息。
1. 当前默认模型：显示 PC / phone / tablet 现在实际在用的模型。
2. 候选模型：显示训练导出的可选模型。先点选，再看详情。
3. 设为默认：把当前选中的候选模型复制到默认模型位置，之后测试台与前端推理会使用它。
4. 评估当前 / 评估全部：重新生成报告并自动刷新索引。
5. Checkpoints / Resume：查看恢复训练配置与当前 checkpoint 状态。
