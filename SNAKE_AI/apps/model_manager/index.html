模型管理台

这是一个给本地使用的统一入口页面。你可以在这里查看当前默认模型、浏览训练产生的候选模型、阅读训练/评估报告、查看 checkpoint 的恢复训练提示，并把某个候选模型直接设为默认模型。

[ 新手说明 ]

这里是统一的模型管理入口：先在右侧候选模型里选中一个模型，再决定是设为默认、重新评估，还是查看它对应的 checkpoint / resume 信息。
1. 当前默认模型：显示 PC / phone / tablet 现在实际在用的模型。
2. 候选模型：显示训练导出的可选模型。先点选，再看右侧详情。
3. 设为默认：把当前选中的候选模型复制到默认模型位置，之后测试台与前端推理会使用它。
4. 打开评估：会先重新评估当前候选模型，再自动打开最新评估报告。
5. Checkpoints / Resume：在主区域切到对应标签后，可以看到 checkpoint 列表和恢复训练配置。
