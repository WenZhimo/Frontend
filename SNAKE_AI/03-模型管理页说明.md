# 模型管理页说明

## 入口

先启动本地服务：

```bash
python apps/model_manager/server.py
```

然后打开：

```text
http://127.0.0.1:8000/apps/model_manager/index.html
```

## 主要功能

### 1. 查看默认模型
管理页会显示当前各设备档位的默认模型：
- PC
- phone
- tablet

这些默认模型实际对应：

```text
data/models/profiles/*.json
```

### 2. 浏览候选模型
候选模型主要来自：

```text
artifacts/models/exports/<profile>/
```

通常会看到：
- `<profile>-<generations>-<seed>-<serial>.json`
- `best-of-batch.json`

### 3. 评估单个模型
你可以直接对某个候选模型发起评估。

评估后通常会生成：
- `<model>.eval-report.json`
- `<model>.eval-report.html`

### 4. 评估全部候选模型
管理页支持批量评估当前候选池。

除了档位目录下的汇总报告外，服务端还会额外写：

```text
artifacts/models/exports/evaluation-report.json
artifacts/models/exports/evaluation-report.html
```

### 5. 查看训练报告与 checkpoint
管理页会读取：

```text
artifacts/models/checkpoints/<profile>/
```

你可以看到：
- 当前 checkpoint 目录
- 训练报告
- 恢复训练提示

### 6. 将候选模型设为默认模型
点击“设为默认”后，会把候选模型写到：

```text
data/models/profiles/<profile>.json
```

这会直接影响浏览器运行测试台和线上默认加载模型。

## 管理页依赖哪些文件

### 默认模型
```text
data/models/profiles/
```

### 候选模型与评估产物
```text
artifacts/models/exports/
```

### checkpoint 与训练历史
```text
artifacts/models/checkpoints/
```

---

## 使用建议

### 典型流程
1. 启动本地服务
2. 打开管理页
3. 浏览候选模型
4. 评估当前模型或全部候选模型
5. 打开评估报告比较分数
6. 将表现最好的模型设为默认模型
7. 再去浏览器运行测试台观察真实表现

### 注意事项
- 管理页不是纯静态页面，必须通过 `server.py` 启动
- 默认模型写回的是 `data/models/profiles/`
- 候选模型和评估报告主要看 `artifacts/models/exports/`
- 训练历史和整群 checkpoint 主要看 `artifacts/models/checkpoints/`
