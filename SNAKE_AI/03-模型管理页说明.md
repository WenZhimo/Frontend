# 模型管理页说明

## 入口

先启动本地服务：

```bash
python apps/model_manager/server.py
```

然后打开：

```text
http://127.0.0.1:8000/apps/model_manager/index.html
```

---

## 页面结构

管理页使用 **顶部一级菜单**，点击后下方内容切换到对应领域：

- 默认模型
- 候选模型
- 手动训练
- 长期训练
- Checkpoints / Resume
- 报告
- 帮助

当前选中的菜单会在刷新后保持（通过浏览器 localStorage）。

---

## 各菜单功能

### 1. 默认模型
显示当前各设备档位的默认模型：
- PC
- phone
- tablet

这些模型实际对应：

```text
data/models/profiles/*.json
```

### 2. 候选模型
#### 浏览候选模型
候选模型来自：

```text
artifacts/models/exports/<profile>/
```

左侧是候选模型列表，右侧显示当前选中模型的详情和相关 HTML 报告入口。

#### Profile 筛选
可以按设备档位过滤候选模型列表。

#### 控制按钮
- **刷新**：重新加载全部数据
- **设为默认**：把当前选中的候选模型复制为对应档位的默认模型
- **评估当前**：对当前选中的模型重新评估并生成报告
- **评估全部候选模型**：批量评估所有候选模型
- **清空评估报告**：清除评估产物（`evaluation-report.*`、`*.eval-report.*`），不会删除模型、checkpoint 或训练报告
- **清空训练数据**：清除 profile 级训练历史和长期训练日志，不会删除各 seed 的训练历史、checkpoint 或模型

### 3. 手动训练
这里可以管理 **手动训练的参数预设**。

#### 预设管理
- **新建预设**：新建一份参数预设，可选从已有预设复制
- **预设下拉**：切换当前查看/编辑的预设；当前激活的预设会显示 `（当前）` 后缀
- **设为当前预设**：将下拉中选中的预设激活为当前预设
- **重命名预设**：修改当前选中预设的名称
- **删除当前预设**：删除当前选中的预设（默认预设不可删除）
- **保存当前预设**：把当前表单中的参数保存到当前激活的预设

#### 参数表单
参数按功能分组、折叠显示：
- 基础参数
- 评分与惩罚
- Checkpoint / Resume

参数名以 **中文名称(英文key)** 格式显示。鼠标悬浮在参数上会显示：
- 功能解释
- 可选值或建议范围

分组折叠状态会在刷新后保持。

#### 启动训练
点击 **应用并启动训练** 后：
- 后端会读取当前激活的预设
- 构造 `TrainingConfig` 并真正调用训练入口
- 训练进行中时按钮会被禁用，文字变为 `训练进行中…`

### 4. 长期训练
和手动训练类似，这里可以管理 **长期自动训练的参数预设**。

#### 额外功能
- 参数分组包括：基础参数、试训门槛、评分与惩罚、Checkpoint / Resume、Hybrid 融合
- **应用并启动长期训练**：读取当前激活预设，构造 `LongRunConfig` 并启动长期训练
- **打开长期训练日志摘要**：直接打开 `run-log-summary.html`

### 5. Checkpoints / Resume
读取：

```text
artifacts/models/checkpoints/<profile>/
```

可以看到：
- 每个 seed 的 checkpoint 状态
- 详细的 resume 配置
- 一键复制 resume 配置到剪贴板

### 6. 报告
#### 报告索引
以卡片形式展示所有 HTML 报告文件。

#### 快捷入口
- 训练报告
- 评估报告
- 长期训练日志摘要

#### 清空评估报告
点击后只删除评估产物：
- `evaluation-report.html/.json`
- `*.eval-report.html/.json`

不会删除训练报告（`training-report.html`）、模型文件或 checkpoint。

### 7. 帮助
#### 运行状态面板
显示当前训练任务的：
- 状态（idle / running / succeeded / failed）
- 类型（manual / long-run）
- 当前预设名称
- 开始/结束时间
- 结果 / 错误

状态每 5 秒自动刷新。如果检测到任务从 running 变成结束状态，会自动刷新页面数据（artifacts、reports、configs）。

#### 新手说明
可折叠的新人使用说明。

## 如何保存和使用多套参数

### 典型流程
1. 切换到 **手动训练** 或 **长期训练** 菜单
2. 展开参数组，调整需要修改的参数
3. 点击 **新建预设**，输入预设名称，可选从已有预设复制
4. 再次调整参数后，点击 **保存当前预设**
5. 需要切换时，通过下拉选另一套预设，再点击 **设为当前预设**
6. 准备好后，点击 **应用并启动训练**

### 如何应用到训练
当你点击"应用并启动"时：
- 后端不会去改 Python 源码
- 而是读取当前激活预设
- 构造对应的配置对象
- 直接调用训练入口函数

这样可以避免污染源码，又能从页面控制训练参数。

---

## 状态持久化
管理页会通过浏览器 localStorage 记住：
- 当前选中的一级菜单
- 每个参数分组的展开/折叠状态

刷新页面后不需要重新选择。

---

## 注意事项
- 管理页不是纯静态页面，必须通过 `server.py` 启动
- 同一时刻只允许一个训练任务运行
- 默认预设（id=`default`）不可删除
- 删除预设时至少保留一个预设
- 训练进行中时启动按钮会自动禁用
- 训练完成后页面数据会自动刷新
