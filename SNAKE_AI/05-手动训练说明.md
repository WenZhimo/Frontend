# 手动训练说明

## 入口

```bash
python src/train/snake_nn/trainer.py
```

对应脚本：

```text
src/train/snake_nn/trainer.py
```

---

## 适合什么场景

手动训练适合：
- 你想手动调参数
- 你想比较不同 seed 的效果
- 你想观察一轮批量实验的结果
- 你想人工决定是否将某个候选模型晋升为默认模型

它更像“实验模式”，不是长期调度器。

---

## 最常改的地方

### 1. `ACTIVE_PROFILE`
决定当前训练的设备档位：
- `pc`
- `phone`
- `tablet`

它会影响：
- 棋盘尺寸
- 默认模型路径
- 导出目录
- checkpoint 目录

### 2. `SEED_BATCH`
决定这一轮要跑哪些随机 seed。

例如：
```python
SEED_BATCH = [23, 56, 947]
```

### 3. `BASE_IDE_CONFIG`
这是手动训练最重要的参数入口。

你通常会在这里调整：
- `generations`
- `num_parents`
- `num_offspring`
- `episodes_per_board`
- `score_weight`
- `survival_weight`
- `population_checkpoint_interval`
- `resume_from_checkpoint`
- `parallel_evaluation_enabled`

---

## 训练时会发生什么

运行后会做这些事：

1. 按 `ACTIVE_PROFILE` 绑定档位配置
2. 逐个运行 `SEED_BATCH` 中的 seed
3. 对每个 seed 训练出候选模型
4. 将候选模型导出到：
   ```text
   artifacts/models/exports/<profile>/
   ```
5. 用统一 episode seed 评估候选模型与当前默认模型
6. 生成比较结果
7. 生成本轮排行
8. 自动把第一名复制成：
   ```text
   best-of-batch.json
   ```

## 主要输出位置

### 候选模型
```text
artifacts/models/exports/<profile>/
```

### 整群 checkpoint
```text
artifacts/models/checkpoints/<profile>/<seed>-latest/
```

### 训练历史与训练报告
```text
artifacts/models/checkpoints/<profile>/training-history.json
artifacts/models/checkpoints/<profile>/training-report.html
```

### seed 级历史
```text
artifacts/models/checkpoints/<profile>/<seed>-latest/training-history.json
```

### 评估报告
```text
artifacts/models/exports/<profile>/*.eval-report.json
artifacts/models/exports/<profile>/*.eval-report.html
```

## 恢复训练

如果你要从整群 checkpoint 恢复训练，在 `BASE_IDE_CONFIG` 里设置：

```python
resume_from_checkpoint='artifacts/models/checkpoints/pc/23-latest'
```

### 注意
- `generations` 表示**目标总代数上限**
- 不是“再加多少代”

例如：
- checkpoint 当前在第 50 代
- 你想继续跑到第 200 代
- 那应该设置：
  ```python
  generations=200
  ```

而不是 150。

### `resume_strict`
- `True`：关键参数必须和 checkpoint 保存时一致，否则拒绝恢复
- `False`：允许近似恢复，但训练轨迹可能不再完全连续

---

## 常见参数说明

### `population_checkpoint_interval`
它控制的是：
- 整群 checkpoint 覆写频率

不是：
- `training-history.json` 的写入频率

### `training-history.json`
训练历史是**每代写**的。

### `parallel_evaluation_enabled`
是否把每代种群评估并行化。

它只影响：
- 种群评估吞吐

不影响：
- 遗传算法演化逻辑本身

---

## 推荐使用流程

1. 先把 `ACTIVE_PROFILE` 改到你要的档位
2. 设置少量 seed 做一轮实验
3. 调 `BASE_IDE_CONFIG` 里的代数 / 种群规模 / 评分权重
4. 运行手动训练
5. 看导出模型和评估结果
6. 选择表现最好的候选模型
7. 再通过管理页决定是否晋升为默认模型
