# TTS 真实波形图片生成器

一个离线源码、浏览器运行的文字转波形图片工具。所有可见波形都来自 Kokoro TTS 生成的真实音频峰值，不使用 C.A.S.S.I.E. 的词库或预置音频素材。

## 两套模式

- 字母发音版：点击“生成 A-Z 字母采样”，工具会用当前 Kokoro 音色、后端、精度和语速生成 26 个字母发音并缓存；之后输入文字时按字母音频拼接。
- 单词发音版：点击“生成输入单词波形”，工具会把当前输入拆成唯一单词/连续文本块，逐个现场 TTS 生成音频，再按原换行、空格和标点间隔拼接。

## 使用

1. 推荐双击 `run-local.bat`，然后打开终端显示的本地地址。
2. 输入或粘贴文字，可使用加粗、斜体、下划线、颜色和字号。
3. 选择“字母发音版”或“单词发音版”，再点击对应生成按钮。
4. 生成完成后可试听拼接音频，并导出 PNG、SVG、WEBP、JPG。
5. 预览画布支持鼠标/触摸拖拽平移，以及 `+` / `-`、适屏、`1:1` 和 `Ctrl + 鼠标滚轮` 缩放。
6. 界面默认使用暗黑模式；点击右上角主题按钮可切换浅色模式，选择会保存在浏览器本地。

## 说明

- 首次生成会从网络加载 Kokoro JS 与模型文件，后续浏览器会缓存。
- 生成进度显示在当前生成按钮所在的模式卡片内，会显示模型加载、当前语音单元和耗时，不需要滚动到左侧面板底部查看。
- 每个 TTS 片段解码后会自动裁剪首尾静音，预览波形和试听音频都会使用裁剪后的结果；低电平弱音仍保留在真实音频中。
- “波形段间距 ms”只影响相邻真实波形段的视觉布局，负值会让相邻段重叠，以缓解裁剪后弱尾音带来的视觉断层；现在支持到 `-1000ms`，不会改变试听音频。
- 生成后的预览图会锚定在画布左上角，避免大图居中后落在当前视口之外。
- “试听拼接音频”是单轨播放控制，重复点击会暂停/继续，不会叠加新的音轨。
- 波形图片直接使用 TTS 音频的高分辨率 min/max 采样路径，并叠加可调的峰值对比度与墨迹扩散；不额外绘制装饰性尖刺线，试听仍播放裁剪后的 TTS 音频。
- “幅度映射”默认使用原版幅度比例；“峰值强调 · 幂律”会在保留正负号和时间位置的前提下压低普通幅度，使真实高峰相对突出；“对数动态范围”会展开较弱信号。两种非线性方式都由“非线性强度”控制；在原版模式下直接拖动该滑块会自动切换到峰值强调。
- “波形细节倍率”控制局部采样密度，最高可到 12 倍；“峰值对比度”继续调节原有的真实采样映射。“墨迹毛边”会放大真实 TTS 采样中的局部突变，让边缘更尖、更接近扫描/印刷时的毛刺；“墨迹扩散”会在同一真实波形路径下增加可调的 SVG 模糊扩散层。两者都不会添加独立装饰线。
- “尖峰锐化”使用真实音频采样中的局部极值做锐化，放大真实尖峰并收窄峰值附近的肩部；“波形不透明度”默认 100%，用于调节波形主体和中心线的整体透明度。
- PNG、WEBP 支持透明背景；JPG 会自动铺白底；SVG 保存真实音频峰值对应的矢量路径。
- 格式保留范围：换行、空格、Tab、文字颜色、加粗、斜体、下划线、字号映射。
- 如果更换音色、后端、精度或语速，需要重新生成当前模式的 TTS 音频。
