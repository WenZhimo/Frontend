ABOUT THIS STUDY

An open re-implementation, not a copy.

The scene is built from scratch around the ideas in the accompanying technical notes: a rounded frame is treated as a refracting solid, flat windows are treated as thin Fresnel shells, and the disc uses a simplified radial-grating model.

The cover art is original or openly licensed. The code is MIT. The plastic and the studio are generated at runtime; there are no HDR environments or album-art textures.

Inspired by public real-time material studies. All code and artwork here are original or openly licensed.
