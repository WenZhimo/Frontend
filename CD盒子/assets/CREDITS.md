# Source Texture Credits

These four images are **source textures** used as backgrounds/ingredients for the
fictional album covers in *Open CD Case*, a non-commercial, open-source WebGL
learning demo. They are not real album artworks, and no artist, label, or
photographer endorses the project.

The final 1024 × 1024 covers at `covers/cover-*.webp` are **composite/derivative
works** created for the demo: the project adds its own typography, vector graphics,
CD/UI mockups, and layout on top of these source textures. The credits below cover
only the four photographic source files in `covers/source-textures/`; the composite
covers' original design elements are not third-party assets.

All sources and licenses were checked on the Wikimedia Commons file page (not just
a search result) on **2026-11-10**. The source textures are 1024 × 1024 WebP, with
160 × 160 WebP thumbnails. No images from any original reference site are used.

## source-holo.webp

- **Title:** *Bismuth Crystal_13x14*
- **Author:** Savannah River Site (photo by James Therrell, Materials Disposition
  Engineering, Savannah River Nuclear Solutions, for the Savannah River Site).
- **Source URL:**
  <https://commons.wikimedia.org/wiki/File:Bismuth_Crystal_13x14_(48869886563).jpg>
  (original Flickr post: <https://www.flickr.com/photos/51009184@N06/48869886563>)
- **Direct source file:**
  <https://upload.wikimedia.org/wikipedia/commons/6/61/Bismuth_Crystal_13x14_%2848869886563%29.jpg>
- **License:** Public domain as a U.S. Department of Energy work
  (**PD-USGov-DOE**, <https://commons.wikimedia.org/wiki/Template:PD-USGov-DOE>).
  The same Commons file page also carries **CC BY 2.0**
  (<https://creativecommons.org/licenses/by/2.0/>). This project relies on the
  public-domain tag; the full author/source/license credit above is provided so
  that the CC BY 2.0 attribution requirement is also satisfied as a fallback.
- **Modifications:** Cropped to a 1270 × 1270 square from the 1950 × 2100 original

- **Note:** Used as a background/ingredient for the fictional “HOLO” cover in the

## Final composite covers

The four files at `covers/cover-*.webp` are original composite designs made for
this project: typography, vector marks, crop, colour grade and layout were added
by the project authors. They are released under **CC0 1.0** to the extent
permitted by the source licenses above. The four source photographs remain under
their own public-domain / CC0 terms and are included in
`covers/source-textures/` for transparency.

The 160 px thumbnails are opaque crops of the same composites and follow the same
terms. No album cover, logo or artwork from any reference site is used.
