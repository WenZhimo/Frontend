# 围棋终端视觉特效方案

## 状态

- 状态：Implemented draft
- 日期：2026-08-12
- 参考实现：`app.js`

## 核心方向

围棋不做棋子移动拖尾。棋子从不滑动，视觉重点放在落子、气、提子、地盘和终局。所有效果都通过字符终端缓冲区与 Braille 子像素层完成，避免直接绘制自由 canvas 粒子。

## 当前实现

- 落子脉冲：新落子从较小圆形点阵凝结成完整石子，同时向周围经纬线发出短暂环形点阵波。
- 气脉呼吸：当一串棋剩 1-2 气时，周围空点出现低亮度呼吸点；剩 1 气时使用红色危险提示。
- 提子消散：被提棋块先保持圆形轮廓，再逐步裂解成红色点阵碎片并淡出。
- 地盘显影：终局后使用 `computeScoringLocations(true)` 获取地盘位置，低亮度显示黑白势力区域。
- 右侧面板：显示规则引擎、AI persona、行棋方、估算比分和最近着法。

## 保留原则

- 棋盘结构感应来自交点经纬线、星位和低密度底噪，不使用普通棋盘格。
- 不把气常驻显示得过重，只在危险棋链周围显现。
- 不把终局地盘做成饱和热力图，保持终端审美中的低亮度、低噪声。
- 后续即使接入更强 AI，视觉事件仍然只读取规则层输出，不把规则判断写进渲染层。

## 后续可增强

- 给不同 AI persona 增加细微落子音型/脉冲节奏差异。
- 为打吃和反打吃增加更清晰的“气口收缩”效果。
- 在终局前的中后盘加入极低亮度的势力 haze，但默认不抢画面。
- 用固定 seed 测试同一局中所有视觉事件的复现性。
