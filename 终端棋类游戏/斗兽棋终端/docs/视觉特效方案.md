# Jungle Terminal Visual Plan

- Board terrain is the star: rivers are animated blue dot currents, traps are red/blue warning lattices, and dens glow as terminal vaults.
- Animals use compact terminal badges: two-character labels combine animal code and rank, backed by side-colored dot clusters.
- Movement leaves a short claw-track trail. Captures burst into radial slash fragments.
- Lion and tiger river jumps create a long horizontal/vertical wake across river cells.
- Den entry triggers a high-intensity vault alarm: concentric dot shockwaves and a persistent winner pulse around the den.
- Canvas remains only the terminal display surface; terrain, pieces, rivers, trails, and bursts are written into character/Braille buffers first.
