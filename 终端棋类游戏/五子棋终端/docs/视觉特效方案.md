# 五子棋终端视觉特效方案

## 状态

- 状态：Implemented draft
- 日期：2026-08-12
- 参考实现：`app.js`

## 核心方向

五子棋的视觉重点不是移动、提子或气，而是“线”。第一版围绕三类线性事件设计：候选威胁线、落子冲击线、胜利五连线。

## 当前实现

- 落子脉冲：新棋子从中心凝结，周围出现短环形点阵波。
- 威胁线：AI 识别到较高价值候选点时，在相关方向显示低亮点阵线段，提示攻防焦点。
- 胜利定格：成五后沿胜利方向绘制亮线，并在终端右侧输出结果。
- 棋子风格：黑方为金橙点阵，白方为亮白/浅青点阵，和其它终端棋类保持统一但不混淆。
- 面板：显示 AI persona、当前回合、威胁等级、最近着法。

## 保留原则

- 线性特效必须由 Braille 点阵构成，不直接画 canvas 线。
- 威胁提示保持低亮度，不能遮住棋子本体。
- 胜利线可以高亮，但只在终局后定格，不在普通回合持续抢画面。
