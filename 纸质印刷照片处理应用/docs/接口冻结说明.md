# 接口冻结说明

## 1. 当前阶段结论

Phase 1 先冻结最小共享接口与目录结构，让后续 M1-M6 可以并行或串行推进而不互相踩线。

当前冻结范围：

- 图像处理共享类型：`src/image-pipeline/types.ts`
- 渲染入口：`renderPrintEffect(input: RenderInput): Promise<RenderOutput>`
- 预设配置入口：`src/presets/index.ts`
- PNG 导出入口：`canvasToPngBlob()` 与 `downloadBlob()`
- 应用壳子入口：`src/app/App.tsx`
- 测试与样例图片约定：`docs/测试与样例图片约定.md` 与 `tests/fixtures/`

这些接口是第一轮模块协作的默认契约。后续如果某个模块确实需要改接口，必须在交付摘要中说明原因、影响面和迁移建议，由主集成者统一修改。

## 2. 目录边界

```text
src/
  app/              React 应用入口、全局状态和页面组合
  components/       可复用 UI 组件，后续由 M2 扩展
  image-pipeline/   Canvas/ImageData 渲染算法，不依赖 React
  presets/          纸张、油墨、默认预设和纹理策略
  export/           PNG 导出和导出尺寸策略
  workers/          Worker / OffscreenCanvas 渲染接入
  styles/           设计 token 和全局样式
tests/
  fixtures/         第一轮 smoke test 样例图片
```

## 3. 共享类型边界

`PrintPreset` 是 UI、预设、渲染和导出的主要连接点。第一轮参数先覆盖：

- `inks`：油墨层、颜色、透明度、角度和偏移；
- `paper`：纸张底色、颗粒、纤维和污点强度；
- `halftone`：网点开关、大小、间距、角度和对比；
- `grain`：颗粒强度、尺度和柔和度；
- `misregistration`：错版强度与随机开关；
- `tone`：亮度、对比度、饱和度和色阶压缩。

## 4. 第一轮模块工作包

### M1 Product / UX

允许修改：

- `docs/项目规格草案.md`
- `docs/视觉验收清单.md`
- 新增 `docs/产品交互说明.md`

交付重点：

- 参数命名和控件分组；
- 空状态、错误状态、大图状态；
- 每个控件到 `PrintPreset` 字段的映射。

### M2 Frontend Shell

允许修改：

- `src/app/*`
- `src/components/*`
- `src/styles/*`
- 与 Vite / React 壳子直接相关的配置。

禁止直接实现真实像素算法；只通过 `src/image-pipeline` 调用渲染。

### M3 Image Pipeline

允许修改：

- `src/image-pipeline/*`
- 算法相关测试或 fixture。

必须保持不依赖 React。固定输入和固定 preset 应输出稳定结果。

### M4 Presets / Textures

允许修改：

- `src/presets/*`
- `public/textures/*`
- `docs/视觉验收清单.md`

不把 preset 硬编码进渲染算法。

### M5 Export / Performance

允许修改：

- `src/export/*`
- `src/workers/*`
- 与导出按钮接入相关的最小 UI 文件。

导出必须复用渲染管线，不复制独立视觉算法。

### M6 QA / Integration

允许修改：

- 测试文件；
- 验证脚本；
- `docs/集成验收报告.md`
- `docs/视觉验收清单.md`

默认不改业务代码，除非主集成者明确授权小修。

## 5. 第一轮验证目标

- `npm run typecheck` 通过；
- `npm run build` 通过；
- `docs/测试与样例图片约定.md` 明确样例图片类别、fixture 放置规则和基础冒烟路径；
- 上传图片、切换预设、导出 PNG 的链路可以在后续实现中围绕当前接口扩展；
- 所有模块都能从 `PrintPreset` 或 `RenderInput` 找到自己的输入边界。
