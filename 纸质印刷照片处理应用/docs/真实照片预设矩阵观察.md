# 真实照片预设矩阵观察

日期：2026-08-19

## 1. 目的

这份记录用于把 `npm run smoke:real:preset-gallery` 生成的真实照片矩阵转换成可讨论的 Phase 2 视觉判断依据。

它不是最终审美验收结论；最终是否需要继续调参仍由用户根据 contact sheet 判断。

## 2. 本轮视觉方向修正

用户进一步明确参考图的关键机制：最终颜色应来自基础色圆点一层一层叠压，而不是直接画出任意颜色的点；同一位置上，各基础色通道的点径可以不同。

本轮实现后，渲染策略调整为：

- 原图局部颜色先被拆成基础油墨通道覆盖率；
- 每个通道只使用自己的固定基础色，例如朱红、孔雀蓝、芥末黄或炭黑；
- 多油墨预设共用同一半调网格，避免多套大角度网格交叉成丝网纹；
- 同一网格位置上，不同通道根据 coverage 生成不同半径和可选形状的圆点；
- 最终颜色由多层圆点 multiply 叠压、轻微错版和纸张纹理共同形成。
- 用户指出旧 `现实彩印` 会造成颜色失真和变淡，适合作为褪色风格但不适合作为“现实”入口；因此先将旧参数保留为 `褪色彩印`，再把 `现实彩印` 改为以颜色还原为优先的 CMYK 分色入口。
- 用户进一步指出 `现实彩印` 仍不够现实，目标应是 CMYK 分色后重新组合能接近原图颜色；因此 `现实彩印` 改为可见的 `CMYK 保真` 分色模式：先按 RGB -> CMYK 得到四版覆盖率，半调开启时用真实 CMYK 圆点筛网输出，半调关闭时才显示连续 CMYK proof。
- 用户继续指出保真模式下网点参数像是在改纹理、点间不出间隙；因此移除了半调开启状态下的连续 proof 底色托底，并增加回归检查：在非白色原图区域，`网点间距 16px` + `网点大小 0.50` 必须显著增加纸白间隙。
- 用户继续指出 `现实彩印` 有轻微过曝；因此 CMYK 半调覆盖率不再把低覆盖率高光直接裁成 0，而是保留少量高光小网点，同时维持中暗部原有密度。
- `色彩保留` 文案改为 `色彩强度`，`色阶数量` 上限提高到 256，避免低色阶造成明显渐变边界。

## 5. 初步观察

- `Soft Paper`：单通道效果最轻，使用柔边圆点，保留柔和纸面和细小点阵，但不承担彩色分层叠印主方向。
- `Riso Bloom`：朱红、孔雀蓝、芥末黄在同一网格上分层叠压，高饱和样本中不同基础色点径差异清楚，是当前最贴近参考机制的预设。
- `现实彩印`：使用 `CMYK 保真` 分色模式，半调开启时输出真实 CMYK 圆点筛网，半调关闭时输出连续 CMYK proof；高光小网点已补回，平均亮度贴近原图，且不再承担褪色风格。
- `褪色彩印`：保留旧 `现实彩印` 的偏淡、轻微失真和褪色效果，适合作为独立审美预设，而不再承担“现实彩色打印”的默认语义。
- `Newspaper Dot`：炭黑单通道网点强，结构清楚，适合新闻纸方向。
- `Mono Grain`：近单色颗粒稳定，整体更像影印或低饱和复印。
- `Warm Poster`：朱红、芥末黄、炭黑叠印强，暗部和主体边缘更重；风格冲击力强，但可能需要后续降低黑版密度。

## 6. 风险与建议

- 自动化指标只能证明非空、不透明、有颜色和亮度变化，不能替代参考图审美判断。
- 本轮已把根机制从“直接彩色点”改为“基础色通道叠印”，但具体观感仍可调。
- 若继续 Phase 2，建议优先审看 `现实彩印`：如果颜色已接近原图但印刷质感不够，可提高 `网点对比`；如果网点仍显硬，可降低 `网点对比` 或增大 `网点间距`。
- 不建议现在进入 Phase 3；应先让用户确认基础色分层叠印方向是否接近期望。
