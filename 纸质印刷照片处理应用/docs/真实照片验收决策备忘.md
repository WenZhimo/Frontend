# 真实照片验收决策备忘

日期：2026-08-19

## 1. 当前结论

用户已选择继续留在 Phase 2，并进一步明确视觉方向：参考图更像是用基础色圆点一层一层叠压，最终混合出各种颜色，而不是直接用任意颜色的点重绘照片；同一位置上，不同基础色通道的圆点大小也应不同。

当前实现已按该方向调整：风格化预设会把原图局部颜色拆成基础油墨通道覆盖率，每个通道使用固定油墨色，在同一半调网格上生成不同半径和形状的圆点，再通过 multiply 叠印、轻微错版和纸张纹理合成最终颜色。旧 `现实彩印` 的偏淡褪色观感已保留为 `褪色彩印`；新的 `现实彩印` 改为 `CMYK 保真` 分色模式，半调开启时通过 RGB -> CMYK -> 当前 CMYK 通道输出真实圆点筛网，半调关闭时才显示连续 CMYK proof。Phase 2 仍不自动进入 Phase 3，需要用户审看最新 contact sheet 后确认是否继续调参。

## 3. 最新实现与验证证据

本轮视觉修正：

- `prepareInkCoverages()` 从原图局部颜色计算各基础油墨通道覆盖率，而不是直接把源图颜色作为点颜色。
- `现实彩印` 使用 `process-cmyk` 分色模式，按标准 RGB -> CMYK 覆盖率生成四版；半调开启时只绘制 CMYK 圆点筛网，半调关闭时绘制连续 proof。
- 每层油墨仍使用自身固定基础色，例如朱红、孔雀蓝、芥末黄或炭黑。
- 多油墨预设共用同一半调网格角度，通道之间主要通过点半径差异和轻微错版形成叠压。
- `drawHalftoneLayer()` 根据每个通道的 coverage 绘制不同大小和形状的圆点，最终通过 multiply 合成混色。
- `drawHalftoneLayer()` 对 `CMYK 保真` 模式加入高光小网点补偿，避免低覆盖率区域被线性对比曲线直接裁成纸白，从而减少轻微过曝。
- `现实彩印` 预设加入默认预设列表，使用理想 CMYK 四通道、白色照片纸、256 色阶和低错版，优先让重组颜色接近原图。
- 参数面板新增可见 `分色模式`，并将 `色彩保留` 改名为 `色彩强度`；`色阶数量` 上限提高到 256。
- `褪色彩印` 保留旧 `现实彩印` 的偏淡、轻微失真和褪色效果，作为独立风格预设。
- 预设现在只作为可见参数快捷起点；纸张、半调、墨点形状、颗粒、错版、色调和每个油墨通道参数均暴露在界面中，色彩通道数量可新增 / 移除，并支持保存为本机自定义预设。

## 5. 预设观察摘要

| 预设 | 当前观察 | 建议 |
| --- | --- | --- |
| Soft Paper | 单通道柔和纸面，柔边圆点更轻，适合作为低强度照片纸方向 | 可保留为柔和入口 |
| Riso Bloom | 朱红、孔雀蓝、芥末黄在同一网格上叠压，通道点径差异明显 | 最接近“基础色圆点叠印”的参考方向 |
| 现实彩印 | `CMYK 保真` 分色，半调开启时是真实 CMYK 圆点筛网，半调关闭时是连续 proof | 作为现实彩色打印入口，继续围绕网点对比、点距和纸面纹理微调 |
| 褪色彩印 | 保留旧现实彩印的偏淡、轻微失真和褪色观感 | 保留为独立褪色风格，不再作为“现实”入口 |
| Newspaper Dot | 炭黑单通道结构最清楚，新闻纸质感强 | 保留为强网点 / 低成本印刷方向 |
| Mono Grain | 近单色颗粒稳定，不承担彩色叠印主方向 | 保留为影印 / 单色印刷风格 |
| Warm Poster | 朱红、芥末黄、炭黑叠印更强，色块冲击大但偏重偏黑 | 可作为高强度海报方向，后续可微调黑版密度 |

## 6. 当前待判断

现在的问题是对“基础色分层叠印”版本做审美判断：

- 如果方向正确：继续在 Phase 2 微调网点对比、网点间距和纸张颗粒。
- 如果仍偏离参考：优先说明是“点太大 / 点太密 / 黑版太重 / 通道错位不足 / 颜色不够轻透 / 太像丝网交叉纹”中的哪一类。
- 在用户确认前，不进入 Phase 3。
