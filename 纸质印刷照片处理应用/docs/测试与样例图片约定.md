# 测试与样例图片约定

## 1. 目的

这份文档冻结第一版测试与样例图片边界，供 M2-M6 在并行或串行开发时使用。它不改变 MVP 范围，只补足 Phase 1 中“测试和样例图片约定”的接口证据。

## 2. 样例图片类型

第一版至少围绕这些图片类型验证：

- `simple-still-life`：简单花草或静物，用于检查网点、纸纹、颜色和柔和感。
- `portrait`：人像，用于检查肤色、五官识别和细节损失。
- `street-lines`：建筑或街景，用于检查线条、边缘、错版和摩尔纹风险。
- `low-contrast`：低对比照片，用于检查对比增强和油墨映射。
- `high-saturation`：高饱和照片，用于检查少色映射是否变脏或变糊。

## 3. Fixture 放置规则

```text
tests/
  fixtures/
    README.md
    simple-still-life.svg
    portrait.svg
    street-lines.svg
    low-contrast.svg
    high-saturation.svg
    local-only/
      real-photos/
        *.jpg / *.jpeg / *.png / *.webp
```

约定：

- 小型矢量 fixture 可以直接提交，方便快速 smoke test。
- 大尺寸照片不直接提交到仓库，除非用户明确授权。
- 如果后续需要真实照片 fixture，应放入 `tests/fixtures/local-only/`，并在 `.gitignore` 中排除。
- 真实照片本地样本默认放入 `tests/fixtures/local-only/real-photos/`，仅接受 `.jpg`、`.jpeg`、`.png`、`.webp`。
- 初始参考截图只用于理解输出气质，不作为真实照片输入 fixture。
- M6 可以基于这些类别补充 Playwright 或手动验收脚本。

## 4. 真实照片本地验证

真实照片验证用于补足 SVG fixture 的局限，重点观察真实像素输入下的肤色、复杂边缘、高饱和区域和低对比区域。

推荐至少放入 5 张样本，对应：

- 静物或花草；
- 人像或人物；
- 建筑、街景或清晰线条；
- 低对比照片；
- 高饱和照片。

运行：

```bash
npm run smoke:real
npm run smoke:real:gallery
npm run smoke:real:preset-gallery
```

规则：

- 默认读取 `tests/fixtures/local-only/real-photos/`。
- 如果需要改目录，可设置 `REAL_PHOTO_DIR` 为项目内相对路径或绝对路径。
- 启用真实照片模式时，如果目录不存在或没有支持格式图片，测试应失败，而不是静默跳过。
- 自动化只验证上传、渲染、画布尺寸、不透明输出、粗略颜色数量和亮度变化；主观“是否足够好看”仍按 `docs/视觉验收清单.md` 做人工判断。
- `npm run smoke:real:gallery` 会额外输出 `tests/fixtures/local-only/real-photo-gallery/index.html`、`manifest.json` 和 `contact-sheet.png`，用于人工并排审阅原图与 `Warm Poster` 处理结果；这些文件仍在 local-only 忽略范围内。
- `npm run smoke:real:preset-gallery` 会额外输出 `tests/fixtures/local-only/real-photo-preset-gallery/index.html`、`manifest.json` 和 `contact-sheet.png`，用于人工审阅 5 张真实照片 × 7 个默认预设的矩阵结果；这些文件仍在 local-only 忽略范围内。

## 5. 基础冒烟路径

M6 的第一轮冒烟测试应覆盖：

1. 打开应用。
2. 空状态可见。
3. 导入 `tests/fixtures/simple-still-life.svg` 或用户提供图片。
4. 预览画布出现。
5. 原图、处理后、对比三种预览模式可切换。
6. 切换至少 4 个预设。
7. 调整网点大小和纸张颜色后，UI 状态更新并可继续渲染。
8. 点击重置后，当前预设的网点大小、纸张颜色和预览模式恢复默认状态。
9. 导出 PNG 按钮可触发导出流程。
10. 上传非图片文件时出现可理解的错误反馈。

## 6. 验证边界

- `npm run typecheck`：验证共享类型和模块调用协议。
- `npm run build`：验证生产构建。
- `npm run smoke`：启动本地 Vite 和 headless Chrome，自动验证上传、预览模式、预设、网点参数、纸张颜色、重置、导出、错误状态、大图和响应式布局。
- `npm run smoke:real`：在 `npm run smoke` 的基础上额外上传本机真实照片样本，并验证输出画布和基础像素指标。
- `npm run smoke:real:gallery`：在 `npm run smoke:real` 的基础上额外生成本机真实照片的原图 / 处理后对照审阅页和 contact sheet。
- `npm run smoke:real:preset-gallery`：在 `npm run smoke:real` 的基础上额外生成所有默认预设在本机真实照片上的矩阵审阅页和 contact sheet。
- 浏览器冒烟测试：验证上传、预设、画布和导出链路。
- 视觉验收：按 `docs/视觉验收清单.md` 判断是否达到“纸质印刷质感”。

## 7. 当前未承诺事项

- 不在 Phase 1 内要求完整 Playwright 自动化。
- 不在 Phase 1 内要求提交真实照片素材库；真实照片样本保持本机 local-only。
- 不在 Phase 1 内要求视觉基准快照。
- 不在 Phase 1 内要求导出文件逐像素对比。
