# 纸质印刷质感照片处理 Web 应用：粗略计划

## 1. 项目定位

做一款浏览器内运行的照片处理 Web 应用，让普通照片呈现接近纸质印刷物的质感。核心感觉不是单纯复古滤镜，而是模拟真实印刷中的半调网点、油墨叠印、轻微套印偏移、纸张颗粒和边缘不完美。

参考方向包括：

- tone：半调网点、层叠油墨、轻微版偏、纸纹、少色印刷感。
- Risograph / screen print / zine aesthetic：双色或三色叠印、纸张吸墨、颗粒噪声、偏移错版。
- Web 图像处理工具：本地上传、本地处理、实时预览、导出成图。

## 2. MVP 功能范围

第一版建议先做到“能用、好看、可调、可导出”：

- 图片上传：支持拖拽、文件选择、粘贴图片。
- 实时预览：原图 / 处理后对比，支持适配画布大小。
- 印刷预设：提供 4-6 个预设，如 Newspaper、Risograph、Warm Paper、Mono Grain、Soft Poster。
- 基础参数：强度、颗粒、对比度、纸张颜色、网点大小、套印偏移。
- 色彩模式：先支持单色、双色、三色；后续再扩展 CMYK。
- 导出：第一版导出 PNG，后续支持 JPEG、PDF、分色图层。

## 3. 核心视觉算法

优先做可解释、可组合的处理管线：

1. 读取图片并标准化到 Canvas。
2. 调整亮度、对比度、饱和度、色调曲线。
3. 将原图映射到少量油墨色板。
4. 对每个油墨通道生成半调网点或颗粒纹理。
5. 给不同油墨通道加入轻微 x/y 偏移，模拟套印不准。
6. 叠加纸张底色、纸纹噪声、轻微纤维纹理。
7. 加入边缘轻微不齐、裁切感或留白边框。

第一版可以用 Canvas 2D + ImageData 实现，后续如果性能不够，再迁移热点算法到 WebGL shader 或 OffscreenCanvas + Worker。

## 4. 界面结构

建议做成工具型界面，而不是营销落地页：

- 顶部栏：项目名、导入、导出、重置。
- 左侧栏：预设列表和纸张/油墨风格。
- 中央区：大画布预览，支持缩放、拖拽、前后对比。
- 右侧栏：参数控制，包括网点、颗粒、偏移、颜色、纸张。
- 底部状态：当前图片尺寸、导出尺寸、处理耗时。

视觉风格可以靠近“印刷工作台”：温暖纸色背景、低饱和控件、黑色细线、少量油墨色作为强调。

## 5. 技术选型建议

推荐从轻量前端开始：

- 构建：Vite
- 语言：TypeScript
- UI：React 或原生 TypeScript 均可；如果希望快且可维护，优先 React。
- 图像处理：Canvas 2D + ImageData
- 性能优化：OffscreenCanvas + Web Worker 作为第二阶段
- 导出：canvas.toBlob / URL.createObjectURL
- 测试：基础单元测试 + 浏览器截图检查

如果后续目标是更高性能实时预览，可以加入 WebGL shader 管线。

## 7. 迭代路线

### Phase 1: 原型

- 建 Vite 项目骨架。
- 完成图片上传与 Canvas 预览。
- 做 2-3 个静态预设。
- 实现基础纸纹、颗粒、对比度和单色半调。

### Phase 2: 印刷感

- 实现双色/三色油墨通道。
- 加入半调角度、点距、点形控制。
- 加入套印偏移和油墨叠印混合。
- 加入纸张材质与手裁边缘。

### Phase 3: 产品化

- 完善参数面板和预设保存。
- 加入前后对比、缩放、导出尺寸。
- 优化大图性能。
- 做移动端适配。

### Phase 4: 高级功能

- 分色导出。
- PDF 导出。
- 自定义油墨色板。
- 批量处理。
- WebGL 实时渲染模式。

## 8. 待讨论问题

- 应用名字和视觉气质：偏日系纸品、zine、海报印刷，还是专业印前工具？
- 第一版是否需要移动端优先？
- 是否必须支持完全离线运行？
- 导出目标是社交分享图，还是可印刷文件？
- 算法优先“真实印刷模拟”，还是优先“好看的艺术滤镜”？
