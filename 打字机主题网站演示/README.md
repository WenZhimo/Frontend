# 我的档案 — 静态打字机主题演示

这是“打字机主题网站”的静态演示版本。它不依赖 WordPress 或构建工具，可以直接被 GitHub Pages、任意静态服务器，或本地 `python -m http.server` 提供。

## 本地运行

在仓库根目录执行：

```bash
python -m http.server 4173 --directory 打字机主题网站演示
```

然后打开 <http://localhost:4173>。

## 交互说明

- 进入首页立即显示完整工作台，打字机在主页纸张上打印欢迎词，不显示开场遮罩。
- 悬停文件夹：只有切换到不同文件夹才会终止上一项打印并保留已打出的文字，回到行首、走纸后追加打印新标题；重复悬停同一文件夹不会重复打印。首字前切换不会新增打印记录，已准备的空行由下一任务复用，不额外换行；键盘聚焦也可预览。
- 首页欢迎词与悬停记录使用缩小后的同一字号和颜色，采用本地「朝华打字机」字体。旧文字只随走纸上移，不缩小、不褪色、不覆盖。
- 所有真正落纸的字符都使用同一套固定的朝华打字机字号和行距；文章分隔标识由 `· · · 文章信息 · · ·` 这类可打印字符组成，分隔标识和元信息只改变墨色，不改变字形尺寸。
- 打印采用固定 23px 字格、固定行距；中文、拉丁字母、数字、标点和空格占用相同字格。长文本在右边界回车，不通过浏览器自动换行重排旧文字。
- 每行先回位、走纸，等待实际动画结束后才落字；每个字先敲击再横向推进，空格只推进、不敲击。整张纸与墨迹一起移动，回车时不会让字体漂浮在静止纸张上。
- 首字前取消任务不增加额外空行；如果已经开始送纸，下一个任务复用该空行，既不再次走纸，也不把纸张倒退回去。返回文章后再次打印，会先送出保留的正文，再在空白处继续打印。
- 纸张向屏幕上方延伸，当前行保持在滚筒上方；历史随换行离开视口，不增加页面高度。内存和 DOM 仅保留最后 100 条信息（多行欢迎词计为一条），刷新后重新开始。
- 点击文件夹：在原纸张先追加带点状分隔线的文章信息，再打印文件编号、标题、作者、日期、分类；打印完成后，镜头用 1.25 秒拉近纸张，正文同时浮现，打印机放大并向下退出视野。当前正文来自本地数据，不插入虚假的网络等待。
- 打印和阅读共用唯一的 `article` 纸张及元信息节点，内部版心固定为 760px；转场仅改变整体缩放与位置，不复制纸张、不重排或替换已打印文字。首页墨迹保留在文章上方，较早记录裁切在视口外。
- 返回首页会倒放进入动画：视角后移、纸张缩小、打字机重新出现；全过程保持原纸张、打印历史、元信息和正文不变。返回后正文保留在滚筒下方的裁切区域，之后的操作继续在原纸张上追加记录。文章标题和元信息始终沿用打印阶段的格式。
- 打印与过渡可被返回首页、浏览器后退或 `Esc` 取消；打印时点击其他文件会立即切换任务，悬停不会打断已点击的文章。打印记录仍遵守 100 条上限。
- `#/slug` 路由支持无刷新导航和前进/后退；直接打开文章链接或启用“减少动态效果”时直接显示正文。
- `Shift + F5` 或阅读页的“重新打印欢迎词”会回到工作台并追加打印欢迎词，已有记录保留。
- 音效默认关闭；开启右上角开关后，可听到浏览器本地合成的敲击、回车音效。系统开启“减少动态效果”时立即显示打印结果。
- 当前文章数据位于 `app.js` 的 `articles` 对象中，后续可把同一接口替换成 WordPress REST API。

## 字体与展示尺寸

- 打印字体源自仓库的 `asset/fonts/朝华打字机/朝華打字機.ttf`，已转换为演示目录内的 WOFF2，独立托管本目录也能加载。
- 全站界面和示例文章均使用中文。预载本地中文字体和 Latin 子集，等待打印字体就绪再落字；正文使用系统宋体，界面使用系统中文字体，无外部字体服务依赖。
- 当前优先宽屏 PC，最小布局宽度 1080px；暂不提供手机单列版面。
