# 洞穴飞行终端

纯本地静态版 Thrust / Gravitar 风格小游戏，视觉层使用固定字符缓冲区渲染到 canvas。飞船、岩壁、能量核心、牵引线、推进尾焰、撞墙爆裂和逃离闪光都由终端字符拼接，不直接绘制自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/洞穴飞行终端/index.html`

## 控制

- `AI DEMO`：飞船自动寻找能量核心并拖曳到出口
- `HUMAN`：`A/D` 或 `←/→` 旋转，`W/↑/Space` 推进
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `V`：返回总入口

## 目标

飞入洞穴，接触能量核心后将其拖到右侧出口。撞到岩壁会爆裂并重新尝试，燃料耗尽会变成漂移状态。

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
