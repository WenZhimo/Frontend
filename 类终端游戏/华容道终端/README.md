# 华容道终端

经典 4x5 华容道的类终端版本。曹操、关羽、将军和兵卒都以字符块呈现，滑动、路径高亮和出口爆闪通过固定字符缓冲区绘制到 canvas。

## 操作

- `AI DEMO`：启发式 AI 自动滑块演示。
- `HUMAN`：方向键或 `W/A/S/D` 移动光标，`Space` 选择棋块，再用方向键推动。
- `1/2/3/4`：播放速度 `0.5x / 1x / 2x / 4x`。
- `P`：暂停。
- `R`：重新随机种子并开局。
- `/`：返回总入口。

## 种子

种子固定为 100 位 ASCII 字符。输入不足 100 位时使用空格补齐；留空会自动生成随机种子。当前版本使用经典横刀立马布局，并由种子决定 AI 回放节奏与背景纹理。
