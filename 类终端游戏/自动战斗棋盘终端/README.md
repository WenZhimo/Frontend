# 自动战斗棋盘终端

纯本地静态版 Auto Battler Lite。两支队伍在棋盘上自动寻敌、普攻、积攒法力并释放技能，战报、伤害数字、治疗、击杀和终局爆发都由终端字符拼接，不直接绘制自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/自动战斗棋盘终端/index.html`

## 控制

- `AI DEMO`：自动编队、自动开战、自动进入下一回合
- `HUMAN`：点击己方单位强化，点击己方半场空格补充单位
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `H`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
