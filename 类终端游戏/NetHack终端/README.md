# NetHack 终端

迷你 Roguelike / NetHack Lite。房间、走廊、怪物、道具、迷雾、战斗日志和掉落都通过固定字符缓冲区绘制到 canvas，尽量保留“终端原生”的味道。

## 操作

- `AI DEMO`：自动探索、拾取、攻击怪物并寻找下一层楼梯。
- `HUMAN`：方向键或 `W/A/S/D` 移动；撞到怪物会攻击；踩到道具会拾取。
- `1/2/3/4`：播放速度 `0.5x / 1x / 2x / 4x`。
- `P`：暂停。
- `R`：重新随机种子并开局。
- `'`：返回总入口。

## 种子

种子固定为 100 位 ASCII 字符。输入不足 100 位时使用空格补齐；留空会自动生成随机种子。相同种子会生成相同地牢、怪物、道具和 AI 演示节奏。
