# 细胞战争终端

纯本地静态版蚁群 / Swarm 模拟小游戏。四个 AI 群体争夺资源、扩张巢穴并互相压制，视觉层使用固定字符缓冲区渲染到 canvas。蚂蚁、资源、信息素、战斗爆点和巢穴压力都由终端字符拼接，不直接绘制自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/细胞战争终端/index.html`

## 控制

- `AI DEMO`：四个群体自动搜集、战斗、繁殖
- `HUMAN`：点击地图投放资源，影响蚁群路线
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `W`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
