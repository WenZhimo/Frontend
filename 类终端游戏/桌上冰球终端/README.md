# 桌上冰球终端

纯本地静态版桌上冰球小游戏，视觉层使用固定字符缓冲区渲染到 canvas。球拍、冰球、拖尾、反弹火花和进球爆裂都由终端字符拼接，不直接绘制自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/桌上冰球终端/index.html`

## 控制

- `AI DEMO`：双方由本地 AI 自动对打
- `HUMAN`：`W/S` 控制左侧球拍，`↑/↓` 控制右侧球拍
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `A`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
