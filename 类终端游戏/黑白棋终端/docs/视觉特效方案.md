# 黑白棋终端视觉特效方案

本项目延续终端棋类系列的视觉语言：深色终端背景、Braille 点阵棋盘、右侧信息面板、顶部 seed 控制条。

## 棋盘

- 8x8 低亮度点阵棋盘。
- 棋格使用固定纯色底与规则网格，合法落点以暗青色点阵提示。
- 棋子用 Braille 点阵圆盘表示，黑方偏橙红，白方偏亮白青。

## 特效

- 落子时产生点阵涟漪与轻微碎片扩散。
- 翻子时沿被翻转方向释放短促线性脉冲，棋子本体有压缩/展开式的点阵变化。
- 终局时胜方棋子低频释放发散粒子，避免遮挡棋盘读盘。

## 实现约束

- canvas 只作为终端字符渲染器。
- 不直接使用 canvas arc、line 或粒子 primitive 表示棋盘和棋子。
- 所有棋盘、棋子、提示和特效都先写入字符/点阵缓冲，再统一渲染。
