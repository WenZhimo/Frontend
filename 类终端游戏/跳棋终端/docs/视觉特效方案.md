# 跳棋终端视觉特效方案

本项目延续同一套终端棋类视觉语言：深色终端背景、Braille 点阵缓冲、右侧信息面板、顶部 seed 控制条。

## 棋盘

- 使用标准中国跳棋 121 孔星形棋盘。
- 每个孔位以低亮度 Braille 点阵呈现，中心六边形与上下目标营地使用不同的暗色层级。
- 棋子仍是由 Braille 点阵组成的圆形弹珠，而不是 canvas 粒子或传统矢量圆。

## 特效

- 落子与跳跃沿用点阵国际象棋中的 `ripples / fragments` 思路。
- 移动开始、跳跃落点会释放椭圆涟漪。
- 移动路径会留下短暂、逐渐散开的同色点阵残影。
- 胜利后目标营地会释放低频发散粒子，避免遮挡棋盘主体。

## 实现约束

- canvas 只作为终端字符渲染器。
- 所有棋盘、棋子、路径和特效都先写入字符/点阵缓冲，再统一渲染。
- 不直接使用 canvas arc、line 或粒子 primitive 表示游戏视觉元素。
