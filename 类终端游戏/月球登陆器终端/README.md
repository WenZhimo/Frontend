# 月球登陆器终端

纯本地静态版 Lunar Lander。重力、推力、燃料、地形、着陆尘埃、坠毁碎片和飞行遥测全部写入固定字符缓冲区，再渲染到 canvas。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/月球登陆器终端/index.html`

## 控制

- `AI DEMO`：自动对准平台并反推减速
- `HUMAN`：`W/↑/Space` 主推力，`A/←` 左姿态喷口，`D/→` 右姿态喷口
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `Y`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
