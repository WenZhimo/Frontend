# 泡泡龙终端

纯本地静态版 Puzzle Bobble 风格小游戏，视觉层使用固定字符缓冲区渲染到 canvas。彩色泡泡、瞄准导线、墙壁反弹、吸附、三连消除、悬空掉落和连锁爆光都由终端字符拼接，不直接绘制自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/泡泡龙终端/index.html`

## 控制

- `AI DEMO`：自动选择可消除或最安全的弹道
- `HUMAN`：`A/D` 或 `←/→` 调整角度，`Space` 发射
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `U`：返回总入口

## 目标

发射泡泡并让同色三颗以上相连即可消除。消除后所有不连到顶部的泡泡会掉落。泡泡压到危险线则失败，清空棋盘则胜利。

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
