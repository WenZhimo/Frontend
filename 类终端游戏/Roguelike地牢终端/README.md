# Roguelike 地牢终端

纯本地静态版迷你 Roguelike。房间、走廊、迷雾、敌人、掉落、出口、战斗 log 和击中特效全部写入固定字符缓冲区，再渲染到 canvas。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/Roguelike地牢终端/index.html`

## 控制

- `AI DEMO`：自动探索、拾取、战斗并寻找出口
- `HUMAN`：方向键或 `W/A/S/D` 移动/攻击；`Space` 原地等待
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `G`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
