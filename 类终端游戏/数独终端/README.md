# 数独终端

9x9 数独的类终端版本。棋盘、候选数、冲突高亮、AI 填数和完成爆闪都通过固定字符缓冲区绘制到 canvas。

## 操作

- `AI DEMO`：按最少候选数策略逐格求解。
- `HUMAN`：方向键或 `W/A/S/D` 移动光标，`Q/E` 切换待填数字，`Space` 填入，`Backspace/Delete` 清空非题目格。
- `1/2/3/4`：播放速度 `0.5x / 1x / 2x / 4x`。
- `P`：暂停。
- `R`：重新随机种子并开局。
- `-`：返回总入口。

## 种子

种子固定为 100 位 ASCII 字符。输入不足 100 位时使用空格补齐；留空会自动生成随机种子。相同种子会生成相同终盘、题目格和 AI 解题顺序。
