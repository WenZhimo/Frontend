# 连连看终端

Match-3 的类终端版本。棋盘、宝石、交换、连锁消除和清屏爆闪都通过固定字符缓冲区绘制到 canvas。

## 操作

- `AI DEMO`：自动寻找高分交换并触发连锁。
- `HUMAN`：方向键或 `W/A/S/D` 移动光标，`Space` 选择/交换。
- `1/2/3/4`：播放速度 `0.5x / 1x / 2x / 4x`。
- `P`：暂停。
- `R`：重新随机种子并开局。
- `.`：返回总入口。

## 种子

种子固定为 100 位 ASCII 字符。输入不足 100 位时使用空格补齐；留空会自动生成随机种子。相同种子会生成相同初始棋盘和 AI 交换序列。
