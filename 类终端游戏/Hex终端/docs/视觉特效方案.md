# Hex Terminal Visual Plan

- The board is a skewed 11x11 rhombus of Braille-built hex cells.
- Empty cells use low-density green-gray dot texture and thin six-edge outlines.
- Red owns west-east; blue owns north-south. The four target rails are drawn as colored terminal dot bus-bars.
- Stones are compact filled hex nodes, not canvas particles.
- Placement emits a short terminal ripple and a small shock burst.
- The winning chain becomes a continuous dot-matrix current, with repeated sparks traveling through each winning cell.
- Canvas remains a terminal renderer: all board, stones, sparks, and currents are first written into character/dot buffers.
