# 百足虫终端

纯本地静态版 Centipede 风格小游戏，视觉层使用固定字符缓冲区渲染到 canvas。百足虫分节移动、蘑菇障碍、跳蚤下落、蜘蛛横跳、炮台射击、分裂波次和爆裂字符雨都由终端字符拼接，不直接绘制自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/百足虫终端/index.html`

## 控制

- `AI DEMO`：炮台自动闪避并优先锁定虫头/近身威胁
- `HUMAN`：`W/A/S/D` 或 `↑/←/↓/→` 移动，`Space` 开火
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `H`：返回总入口

## 目标

清空所有百足虫分节并撑过多轮虫潮。打中身体会把虫体分裂，虫段撞上蘑菇会下压转向；蘑菇可被多次射击摧毁。

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
