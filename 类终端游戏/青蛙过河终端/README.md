# 青蛙过河终端

纯本地静态版 Frogger。车流、河流、木板、乌龟、青蛙、撞击、落水和到达目标的爆闪全部写入固定字符缓冲区，再渲染到 canvas。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/青蛙过河终端/index.html`

## 控制

- `AI DEMO`：自动判断车流和木板，尝试连续渡河
- `HUMAN`：方向键或 `W/A/S/D` 跳跃；`Space` 等待
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `F`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
