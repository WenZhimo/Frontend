# 俄罗斯方块终端

同“类终端游戏”系列风格的本地静态 Tetris inspired 小游戏。

- 渲染方式：固定字符缓冲区 + canvas 字符绘制。
- 随机：每局由 100 位 ASCII 种子驱动 7-bag 方块序列，同一种子可复现同一组方块。
- 玩法：支持 `HOLD`、ghost projection、软降、硬降、旋转和消行。
- AI：`AI DEMO` 使用启发式自动落点，综合消行、洞、堆高、起伏和井位评估。
- 视觉：方块、投影、硬降拖尾、锁定火花、消行爆裂均由终端字符拼接。
- 操作：方向键/A/D 移动，S/Down 软降，Z/X 或 Up 旋转，Space 硬降，H/Shift hold，P 暂停，R 重开，1-4 调速，T 返回总入口。

启动：

```bat
start.bat
```
