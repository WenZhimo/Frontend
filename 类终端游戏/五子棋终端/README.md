# 五子棋终端

终端风格五子棋自动对局原型。页面使用 `<canvas>` 模拟固定字符终端，棋盘、棋子、威胁线和胜负特效均先写入字符/Braille 点阵缓冲区，再统一渲染。

## 当前状态

- 状态：Prototype
- 日期：2026-08-12
- 规则：自由五子棋，15x15，黑白交替，任意方向五连或以上获胜
- AI：本地 seeded heuristic personas，优先识别成五、活四、冲四、活三和防守点
- 视觉：落子脉冲、候选威胁线、胜利五连扫描定格

## 运行

直接打开 `index.html` 即可运行；也可以双击 `start.bat` 启动本地 HTTP 并自动打开页面。

## 操作

- `RANDOM`：生成新 seed 并重开
- `COPY`：复制当前 100 位 ASCII seed
- `PLAY`：使用输入框 seed 重开
- `1 / 2 / 3 / 4`：播放速度 0.5x / 1x / 2x / 4x
- `Space`：暂停/继续
- `R`：reroll，新 seed 重开
- `P`：使用当前 seed 重开
