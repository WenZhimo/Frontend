# 激光推箱子终端

推箱子 + 激光机关的类终端版本。箱子、镜面、激光发射器、接收器、光路和完成爆闪全部通过固定字符缓冲区绘制到 canvas。

## 操作

- `AI DEMO`：自动回放一条预置解法，把箱子推到目标并点亮接收器。
- `HUMAN`：方向键或 `W/A/S/D` 移动并推箱子。
- `1/2/3/4`：播放速度 `0.5x / 1x / 2x / 4x`。
- `P`：暂停。
- `R`：重新随机种子并开局。
- `=`：返回总入口。

## 种子

种子固定为 100 位 ASCII 字符。输入不足 100 位时使用空格补齐；留空会自动生成随机种子。当前版本使用稳定机关关卡，由种子决定背景纹理、光束闪烁和 AI 回放节奏。
