# Dwarf Fortress 终端

小型殖民地模拟 / Dwarf Fortress Lite。矮人、矿脉、树木、农田、工坊、库存、事件流都通过固定字符缓冲区绘制到 canvas。

## 操作

- `AI DEMO`：矮人自动采矿、伐木、搬运、种植、酿造和制作。
- `HUMAN`：方向键或 `W/A/S/D` 移动监察光标，`Space` 在光标处指定采掘/采集。
- `1/2/3/4`：播放速度 `0.5x / 1x / 2x / 4x`。
- `P`：暂停。
- `R`：重新随机种子并开局。
- `,`：返回总入口。

## 种子

种子固定为 100 位 ASCII 字符。输入不足 100 位时使用空格补齐；留空会自动生成随机种子。相同种子会生成相同地形、资源、矮人初始状态和事件节奏。
