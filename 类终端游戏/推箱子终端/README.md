# 推箱子终端

纯本地静态版 Sokoban。地图、墙体、目标点、箱子、人物、AI 路径、推箱火花和通关爆发全部写入固定字符缓冲区，再渲染到 canvas；不会用普通 canvas 粒子替代终端字符特效。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/推箱子终端/index.html`

## 控制

- `AI DEMO`：本地 BFS 解法自动完成当前种子关卡
- `HUMAN`：方向键或 `W/A/S/D` 移动，推箱自动触发；`U` 撤销一步
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `O`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
