# 落球迷宫终端

Peggle / Pachinko Lite 的类终端版本。画面通过固定字符缓冲区渲染到 canvas，球、钉阵、倍率槽、碰撞火花和得分爆闪全部由字符组成。

## 操作

- `AI DEMO`：自动瞄准高价值槽并连续发球。
- `HUMAN`：`A/D` 或方向键调整发射口，`Space` 发球。
- `1/2/3/4`：播放速度 `0.5x / 1x / 2x / 4x`。
- `P`：暂停。
- `R`：重新随机种子并开局。
- `;`：返回总入口。

## 种子

种子固定为 100 位 ASCII 字符。输入不足 100 位时使用空格补齐；留空会自动生成随机种子。相同种子会生成相同钉阵、倍率槽和 AI 开局节奏。
