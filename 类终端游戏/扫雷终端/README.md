# 扫雷终端

纯本地静态版 Minesweeper。隐藏格、数字、旗帜、AI 推理提示、爆雷和清盘特效全部使用固定字符缓冲区渲染到 canvas。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/扫雷终端/index.html`

## 控制

- `AI DEMO`：自动执行基础扫雷推理，无法确定时选择低风险格
- `HUMAN`：方向键或 `W/A/S/D` 移动光标，`Space/Enter` 翻开，`F` 插旗
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `N`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
