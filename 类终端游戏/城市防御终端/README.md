# 城市防御终端

纯本地静态版 Rampart 风格城市防御小游戏。玩家修补城墙、放置炮台，抵御四周舰队炮击；舰船、炮弹、城墙破碎、修墙阶段和爆裂特效都由终端字符拼接，不直接绘制自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/城市防御终端/index.html`

## 控制

- `AI DEMO`：自动修墙、放炮并防守
- `HUMAN`：点击城内空格修墙；点击城内墙体升级炮台
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `[`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
