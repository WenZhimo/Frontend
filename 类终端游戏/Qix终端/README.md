# Qix 终端

纯本地静态版 Qix 画线占地小游戏，视觉层使用固定字符缓冲区渲染到 canvas。占地区域、活动画线、Qix 电弧、Sparx 巡边、封闭填充、撞线惩罚和占地爆光都由终端字符拼接，不直接绘制自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/Qix终端/index.html`

## 控制

- `AI DEMO`：自动从边界切入、闭合小区域并避开 Qix
- `HUMAN`：`W/A/S/D` 或 `↑/←/↓/→` 移动，`Space` 从已占地区域切入画线
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `Q`：返回总入口

## 目标

从已占边界向内画线并回到占地区域闭合路径。闭合后，所有不含 Qix 的封闭区域会被填充；占地率达到目标即胜利。画线时被 Qix 或 Sparx 碰到会损失生命并清除当前轨迹。

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
