# 塔防终端

纯本地静态版路径塔防小游戏，视觉层使用固定字符缓冲区渲染到 canvas。敌人沿种子生成的路线推进，炮塔自动索敌，弹道、伤害数字、爆裂和波次日志都由终端字符拼接，不直接绘制自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/塔防终端/index.html`

## 控制

- `AI DEMO`：系统自动建塔、升级和防守
- `HUMAN`：点击地图空格建塔；同一格再次点击会升级
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `O`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
