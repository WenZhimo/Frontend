# 小行星终端

纯本地静态版 Asteroids，小行星、飞船、推进器尾焰、激光弹道和碎裂爆发都通过固定字符缓冲区绘制到 canvas，保持类终端游戏系列的视觉语言。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/小行星终端/index.html`

## 控制

- `AI DEMO`：飞船自动规避、瞄准和射击
- `HUMAN`：`←/→` 或 `A/D` 旋转，`↑/W` 推进，`Space` 射击
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `X`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
