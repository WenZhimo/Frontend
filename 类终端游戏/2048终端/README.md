# 2048 终端

纯本地静态版 2048。棋盘、数字块、滑动轨迹、合并爆光、分数和 AI 思考日志都由固定字符缓冲区渲染到 canvas，不直接绘制自由图形或自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/2048终端/index.html`

## 控制

- `AI DEMO`：启发式 AI 自动选择方向
- `HUMAN`：`W/A/S/D` 或方向键滑动
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `]`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
