# 光轮终端

纯本地静态版 Light Cycle / Tron 光轮。双方持续留下霓虹轨迹，撞墙或撞线判负；终局爆裂、轨迹辉光和 HUD 都通过固定字符缓冲区渲染到 canvas。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/光轮终端/index.html`

## 控制

- `AI DEMO`：多辆光轮自动转向避障和围堵
- `HUMAN`：`W/A/S/D` 或方向键控制白色光轮转向
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `L`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
