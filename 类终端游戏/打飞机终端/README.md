# 打飞机终端

纯本地静态版 1942 风格纵向射击小游戏，视觉层使用固定字符缓冲区渲染到 canvas。玩家炮机、僚机、敌机波次、Boss 装甲、弹道、拖尾和爆炸字符雨都由终端字符拼接，不直接绘制自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/打飞机终端/index.html`

## 控制

- `AI DEMO`：炮机自动闪避、锁定敌机并开火
- `HUMAN`：`W/A/S/D` 或 `↑/←/↓/→` 移动，`Space` 开火
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `J`：返回总入口

## 目标

击落敌机、拾取僚机支援，撑过敌方波次并击破 Boss。敌弹命中或撞机会损失生命，生命归零则任务失败。

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
