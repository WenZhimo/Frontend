# 生命游戏终端

纯本地静态版 Conway's Game of Life，视觉层使用固定字符缓冲区渲染到 canvas。细胞、出生、死亡、稳定告警和补种脉冲都由终端字符组成，不直接绘制自由粒子。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/生命游戏终端/index.html`

## 控制

- `AI DEMO`：自动演化，稳定后会按种子补入小型结构
- `HUMAN`：默认暂停，可用鼠标点击或键盘编辑细胞
- `W/A/S/D` 或 `方向键`：移动编辑光标
- `Space`：切换光标处细胞
- `N`：单步演化
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停 / 继续
- `R`：重新随机种子并开局
- `Z`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
