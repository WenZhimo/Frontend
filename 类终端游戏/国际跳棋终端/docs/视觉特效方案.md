# 国际跳棋终端视觉特效方案

本项目延续终端棋类系列：深色终端背景、Braille 点阵棋盘、右侧信息面板、顶部 seed 控制条。

## 棋盘

- 10x10 棋盘，只强调可行动的深色斜格。
- 深色格用规则点阵纹理区分，浅格保持低存在感。
- 兵与王都使用 Braille 点阵圆盘，王棋额外叠加冠状点阵环。

## 特效

- 普通移动带短促落点涟漪。
- 吃子跳跃沿斜线释放同色残影，落点释放国际象棋同款点阵涟漪。
- 被吃棋子在原位崩散为点阵碎片。
- 升王时释放更亮的短促爆发，王棋冠环稳定显示。

## 实现约束

- canvas 只作为终端字符渲染器。
- 不直接使用 canvas arc、line 或粒子 primitive 表示棋盘和棋子。
- 所有棋盘、棋子、路径、涟漪和碎片都先写入字符/点阵缓冲，再统一渲染。
