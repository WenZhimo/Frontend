# 弹珠台终端

纯本地静态版 Pinball。弹球、挡板、保险杠、目标灯、轨道、拖尾和加分爆闪全部写入固定字符缓冲区，再渲染到 canvas。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/弹珠台终端/index.html`

## 控制

- `AI DEMO`：自动发球并根据球位击打左右挡板
- `HUMAN`：`A/←` 左挡板，`D/→` 右挡板，`Space` 发球
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `E`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
