# 导弹指挥官终端

纯本地静态版 Missile Command。城市防御、来袭导弹、拦截弹、空中爆裂光团和城市摧毁效果全部使用固定字符缓冲区绘制到 canvas。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/导弹指挥官终端/index.html`

## 控制

- `AI DEMO`：自动选择最危险的导弹并发射拦截弹
- `HUMAN`：鼠标/触摸移动瞄准，点击或 `Space` 发射
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `D`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
