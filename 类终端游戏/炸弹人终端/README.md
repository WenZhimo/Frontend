# 炸弹人终端

纯本地静态版 Bomberman。地图、炸弹倒计时、十字爆炸、软墙破碎、连锁爆炸和 AI 行动都通过固定字符缓冲区渲染到 canvas。

## 启动

- 双击 `start.bat`
- 或从项目总入口进入
- 也可以在 `类终端游戏` 目录启动 HTTP 服务后访问 `/炸弹人终端/index.html`

## 控制

- `AI DEMO`：多名 Bomber 自动移动、投弹和避险
- `HUMAN`：`W/A/S/D` 或方向键移动，`Space` 放炸弹
- `1/2/3/4`：播放速度 `0.5x/1x/2x/4x`
- `P`：暂停
- `R`：重新随机种子并开局
- `M`：返回总入口

## 种子

种子为 ASCII 字符，内部固定补齐到 100 位。留空启动时会生成随机种子，`COPY` 会复制补齐后的 100 位种子。
